## 2. 교구 차이표 (빅아이 로보독 → AI 포니봇)

| 항목 | 빅아이 로보독(현재 사이트) | AI 포니봇 | 사이트 영향 |
|---|---|---|---|
| 구동 | 다리(서보 관절) | 4바퀴 메카넘(DC 모터, PCA9685) **[소스]** | 3D 관절 모형·운동학 불필요 → **2D 위에서 보기(수준 1)로 충분**. 옆 이동·대각 이동을 2D에 표현 |
| 값 범위 | 기존 속도 한도 30(교사 정책) | 속도 0~255, 서보 0~180° **[소스]** | 시뮬은 0~255 그대로. 도우미 속도 한도는 교사가 새로 정함(기존 값을 기본으로 둘지 결정 필요) |
| 거리 센서 | 0 = 못 읽음 처리 | **반사 없으면 500(최대값)을 돌려줌** — 0이 아님 **[소스]** | ⚠ 안전 규칙 수정 필요: "못 읽음 = 아주 멀다"로 보여 계속 직진할 수 있음. 도우미·예제·시험에 반영 |
| 추가 센서 | 거리 위주 | 라인 2개, 컬러 센서(V1/V2 초기화 블록 필요) | 라인 따라가기·색 멈춤 예제 가능. 시뮬에 바닥 선·색 타일 필요(수준 1 범위 안) |
| 화면·빛 | 마이크로비트 LED | + OLED 128×64, 네오픽셀 4개(별도 확장) | 예제에서 OLED로 인식 결과 표시 가능. 조명은 확장 2개 필요 |
| AI 통신 | 웹캠 → USB 시리얼 → 라디오 | 공식 앱은 **스마트폰 → 블루투스 UART**(분석 블록 포함) **[소스]** | 우리 브리지는 라디오 경로 유지. 마이크로비트는 **블루투스와 라디오 동시 사용 불가** → 수업 자료에 "공식 앱(블루투스)과 섞지 않기" 안내 |
| 초기화 | — | PCA9685 자동 초기화, 컬러 센서는 초기화 블록 필요 **[소스]** | 예제 시작 블록에 컬러 초기화 |
| 버튼 | 가려짐 여부에 따라 수업 흐름 달라짐 | **[실물]** | 가려지면 본체 버튼/라디오 리모컨 흐름 유지 |
