## 2. AI 브리지 자동 시험 (27/27 통과)

환경: 헤드리스 크로미움 + **가짜 카메라(색 조절)** + **가짜 Web Serial(전송 기록)**, 로컬 http 서버

| 시험 | 결과 |
|---|---|
| 동봉 모델 로딩(인터넷 CDN 미사용) | 통과 |
| 꾹 누르기 약 4장/초, 클릭 1장 | 통과 (6초에 25장) |
| 시리얼 115200·micro:bit 필터 | 통과 |
| 빨강→1, 노랑→2, 초록→3, 배경→4 전송 | 통과 |
| 같은 값 반복 간격 | 통과 (약 0.5초: 500ms + 처리 주기) |
| 사진 모으는 중 0 | 통과 |
| 멈춤 잠금 중 0 유지 / 풀면 복귀 / Esc | 통과 |
| 확신 기준 미달 시 0 | 통과 (반반 섞인 화면, 기준 100%) |
| 수동 보내기 반복 | 통과 |
| 탭 가림 시 0 | 통과 (visibilitychange 모의) |

| 이름 입력 XSS 차단 | 통과 |

관찰: 학습하지 않은 **파란색을 '초록 100%'로 오답**, 주황·빨강/노랑 반반 화면도 확신 미달 없이 답함 —
결함이 아니라 KNN의 성질이며 수업 소재로 문서에 반영. ('확신 미달→0' 시험은 노랑/초록 반반 화면에서 28회 확인, 위반 0)
file://로 열면 동봉 모델 대신 인터넷(TF Hub, 같은 버전)에서 받아 동작함(확인). 두 모델의 특징값 최대 차이 0.
