# 2차시 소개형 — "AI가 보고, 로봇이 움직여요"

- 대상: 초등 5~6학년 (3~4학년은 교사 시연 비중을 높여 운영)
- 시간: 2차시(80분) 연속 블록 권장
- 목표
  1. 피지컬 AI가 "보고(인식) → 판단하고 → 움직이는" 로봇임을 말할 수 있다.
  2. AI에게 예시 사진을 보여 주어 학습시키고, 그 결과로 로보독을 움직여 본다.
- 성격: 체험·동기유발 중심. 코딩은 **완성 코드를 내려받아 숫자만 바꾸는 수준**.

## 준비물 (모둠 4명 기준)

| 품목 | 수량 | 비고 |
|---|---|---|
| 빅아이 로보독 | 모둠당 1 | 충전 완료 |
| 마이크로비트 V2 | 모둠당 2 | 1개는 로보독 등에, 1개는 PC USB(다리 역할) |
| 웹캠 있는 PC(크롬/엣지) | 모둠당 1 | 노트북 내장 캠 가능 |
| 색 카드(빨강·노랑·초록) | 모둠당 1세트 | 색종이를 A6 크기로 |
| 교사 사전 작업 | - | 마이크로비트에 예제 미리 다운로드, 모둠번호 라벨 부착 |

교사 사전 작업
1. 다리 마이크로비트에 `makecode/00_bridge-receiver.ts`, 로보독 마이크로비트에 `makecode/03_ai-traffic-dog.ts` 다운로드
   (모둠마다 `모둠번호`를 1, 2, 3… 으로 바꿔서)
2. 각 PC에서 AI 브리지 페이지를 한 번 열어 "AI 준비 완료"가 뜨는지 확인(모델 다운로드)
3. 책상 가장자리에서 로보독이 떨어지지 않게 바닥 또는 테두리 있는 공간 확보

## 1차시 (40분) — 로보독 만나기

| 단계 | 시간 | 활동 | 자료 |
|---|---|---|---|
| 도입 | 5분 | 로보독 동작 시연. "이 로봇은 어떻게 알고 움직일까?" 질문 | 로보독 |
| 개념 | 10분 | 피지컬 AI = 눈(센서·카메라) + 뇌(AI) + 몸(모터). 청소로봇·자율주행차·배달로봇 사례 | 마이크로비트 기초 교안 CH1 슬라이드 |
| 관찰 | 10분 | 로보독 부품 찾기 놀이: 눈 LED, 몸통 LED, 거리센서, 카메라, 마이크로비트 자리 | 기초 교안 CH2 |
| 체험 | 12분 | `01_hello-robodog` 실행: A=인사, B=조금 걷기, A+B=앉기. 숫자(속도·시간) 하나 바꿔 다시 다운로드 | MakeCode |
| 정리 | 3분 | "로보독은 아직 *보고* 판단하지는 못했다" → 다음 시간 예고 | |

## 2차시 (40분) — AI 신호등 안내견

| 단계 | 시간 | 활동 | 자료 |
|---|---|---|---|
| 도입 | 5분 | 시각장애인 안내견 영상/사진. "로봇 안내견이 신호등을 보려면?" | 스크래치 AI 교안 CH10 도입 |
| 학습 | 12분 | AI 브리지에서 1 빨강, 2 노랑, 3 초록, 4 배경을 **각 30장 이상** 모으기 | `bridge/index.html` |
| 시험 | 8분 | 카드를 보여 주며 인식 확인 → 마이크로비트 연결 → 로보독이 멈춤/기다림/출발 | |
| 탐구 | 10분 | 일부러 틀리게 만들기: ① 사진 5장만 ② 어두운 곳 ③ 주황색 카드 → AI가 왜 헷갈릴까? | 활동지 |
| 정리 | 5분 | "AI는 **보여 준 예시(데이터)**로 배운다. 데이터가 나쁘면 AI도 틀린다." 안전 이야기: 진짜 안내견 로봇이 틀리면? | |

## 활동지 (2차시 탐구용, 그대로 출력 가능)

```
[AI 신호등 안내견 실험]                        모둠: ____  이름: ________

1. 사진을 몇 장 모았을 때 잘 맞혔나요?
   빨강 ___장 / 노랑 ___장 / 초록 ___장 / 배경 ___장

2. AI를 헷갈리게 만든 방법과 결과
   | 바꾼 것            | AI의 답       | 확신도 |
   | 사진을 5장만 모음  |               |    %   |
   | 어둡게 함          |               |    %   |
   | 주황색 카드를 보임 |               |    %   |

3. 진짜 길에서 로봇 안내견이 틀린다면 어떤 일이 생길까요?
   ____________________________________________

4. AI를 더 똑똑하게 하려면? ______________________
```

## 교사 팁

- 확신도 기준(슬라이더)은 75%로 시작. 자꾸 "잘 모르겠어요"가 나오면 사진을 더 모으게 하세요.
- 신호가 2초 끊기면 로보독이 자동으로 멈춥니다(안전장치). 로보독 마이크로비트 A 버튼 = 비상 정지.
- 같은 반에서 모둠번호가 겹치면 다른 모둠 로보독이 움직입니다. 번호 라벨을 꼭 붙이세요.
- 평가: 관찰 체크(◎○△) — ① 학습 데이터를 모았다 ② AI가 틀리는 이유를 말했다 ③ 안전 규칙을 지켰다.
