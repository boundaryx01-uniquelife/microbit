# 4차시 기본형 — "규칙으로 움직이는 로봇 vs 배워서 움직이는 로봇"

- 대상: 초등 5~6학년 (중학교는 `06_중고등_확장안.md` 참고)
- 시간: 4차시(40분 × 4, 2+2 블록 권장)
- 목표
  1. 순차·조건 구조로 로보독을 움직이는 프로그램을 만든다.
  2. 사람이 정한 **규칙(센서+조건문)**과 예시 데이터로 **학습한 AI**의 차이를 설명한다.
  3. AI 인식 결과를 이용해 생활 속 문제를 돕는 로보독 동작을 설계·구현한다.
- 준비물·교사 사전 작업: `01_소개형_2차시.md`와 같음 + 모둠 주제용 그림 카드(아래 4차시 표 참고)

## 차시 개요

| 차시 | 주제 | 핵심 개념 | 예제 |
|---|---|---|---|
| 1 | 로보독과 첫 만남 | 피지컬 AI, 순차 구조 | `01_hello-robodog` |
| 2 | 규칙으로 반응하기 | 센서, 조건문(만약~라면) | `02_distance-rule` |
| 3 | 배워서 반응하기 | 예시 데이터·학습·확신, 라디오 통신 | `00_bridge-receiver`, `03_ai-traffic-dog` |
| 4 | 우리 모둠 AI 로보독 | 문제 정의·설계·구현·공유, AI 윤리 | `04_ai-team-template` |

모든 차시: **앞 5분 배부·연결, 뒤 5분 정리·회수**를 시간표에 포함했습니다.

## 1차시 — 로보독과 첫 만남 (40분)

| 시간 | 활동 |
|---|---|
| 5분 | 배부·전원, 안전 약속(떨어뜨리지 않기·속도 30 이하·멈춤 버튼) |
| 5분 | 로보독 시연, "피지컬 AI" 낱말 소개 |
| 5분 | 부품 관찰(눈·몸통 LED, 거리센서, 카메라, 마이크로비트 자리) |
| 5분 | MakeCode 확장 추가: `kocoafab/robodog` **전체를 입력**해야 검색됨 (교사 화면 따라 하기) |
| 15분 | 순차 코딩: 표정 → 소리 → 인사 자세 → **마지막에 '준비' 자세**. 다운로드 → 로보독에 꽂기 |
| 5분 | 짝에게 "인사 장면" 보여 주기, 정리 |

## 2차시 — 규칙으로 반응하기 (40분)

| 시간 | 활동 |
|---|---|
| 5분 | 배부·`02_distance-rule` 넣기(교사 사전 다운로드 권장) |
| 3분 | "로봇이 벽에 부딪히지 않으려면 무엇이 필요할까?" |
| 8분 | **A 버튼으로 거리 값 보기**(로봇은 움직이지 않음). 손을 가까이/멀리 → 값 기록 |
| 5분 | 모둠이 "가까움" 기준값을 정하고 코드의 `가까움기준` 숫자 바꾸기 |
| 10분 | 다운로드 → **B 버튼으로 걷기 시작/멈춤**. 손을 대면 멈추고 경고하는지 확인 |
| 4분 | **"이 로봇은 사람이 정한 규칙대로만 움직인다."** 질문: "빨강·노랑·초록 카드를 보고 다르게 움직이게 하는 규칙은? 그림 카드(땅콩·우유)라면?" |
| 5분 | 정리·회수 |

## 3차시 — 배워서 반응하기 (40분)

| 시간 | 활동 |
|---|---|
| 5분 | 배부·연결(로보독에 03, PC에 USB 마이크로비트), AI 브리지 열기 |
| 3분 | 2차시 질문 이어가기: "그림을 규칙으로 설명하기 어렵다면, **보여 주며 가르치자!**" |
| 10분 | AI 학습: 빨강·노랑·초록·배경 카드 각 20장 이상(조금씩 움직이며, 종류별 비슷한 수로) |
| 4분 | 연결 이해: 웹캠 → AI → USB 마이크로비트 → 라디오 → 로보독 (칠판 그림) |
| 8분 | 시험 + 코드 바꾸기: `신호에반응하기` 함수에서 한 신호의 행동(색·소리·표정)을 모둠이 바꾸어 다시 다운로드 |
| 5분 | 규칙 vs 학습 비교표 작성(아래) |
| 5분 | 정리·회수 |

| | 규칙 로봇(2차시) | AI 로봇(3차시) |
|---|---|---|
| 누가 기준을 정했나? | 사람이 숫자(기준값)를 정함 | 사람이 고른 **예시 사진과 이름표**로 AI가 기준을 찾음 |
| 잘하는 일 | | |
| 틀리는 경우 | | |

> 교사용: 두 방식 모두 **사람의 선택**이 들어갑니다(규칙은 기준값, AI는 어떤 사진을 어떤 이름으로 보여 줄지).
> 색 3가지는 사실 색값(RGB) 규칙으로도 만들 수 있습니다. 학생이 이를 지적하면 칭찬하고, "그럼 땅콩 그림과 우유 그림은?"으로 이어 가세요.

## 4차시 — 우리 모둠 AI 로보독 (40분)

| 시간 | 활동 |
|---|---|
| 5분 | 배부·연결. 문제 고르기(아래 표) |
| 7분 | 설계표 작성: "AI가 무엇을 보면(카드 1~3) → 로보독이 무엇을 하나" (`04_활동지_평가.md` 활동지 C) |
| 15분 | AI 브리지에 모둠 카드 학습 → `04_ai-team-template`의 TODO 채우기 → 시험 |
| 4분 | 윤리 점검: ① 사람 얼굴을 찍지 않았나? ② AI가 틀리면 누가 확인하나? ③ 틀렸을 때 위험하지 않게 멈추나? |
| 5분 | 모둠 시연 + 칭찬 한마디 |
| 4분 | 정리·회수·학습 데이터 '모두 지우기' |

| 주제 | 카드 1 | 카드 2 | 카드 3 | 준비물 |
|---|---|---|---|---|
| 급식 알레르기 탐지견 | 땅콩 그림 | 우유 그림 | 안전한 음식 그림 | 그림 카드(교사 출력) |
| 교실 도우미견 | 손바닥 펴기("조용히" 신호) | 정리 시간 카드 | 쉬는 시간 카드 | 카드 2장 |
| 내 물건 알아보는 반려견 | 내 필통 | 친구 필통 | 지우개 | 학생 물건 |
| 위험 알림견 | 위험 표지 그림 | 미끄럼 주의 그림 | 안전 표지 그림 | 그림 카드 |

※ 사람 얼굴을 학습하는 주제(친구 맞이 등)는 쓰지 않습니다. 손 모양은 **얼굴이 화면에 나오지 않게** 손만 비추세요.
