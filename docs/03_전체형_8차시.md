# 8차시 전체형 — "로보독과 함께하는 피지컬 AI 문제해결"

- 대상: 초등 5~6학년
- 시간: 8차시(2차시 × 4블록)
- 바탕 자료: 코코아팹×서울대 8차시(창의적 문제해결 4단계, 활동지·평가 틀)
  + 스크래치 인공지능 교안 CH10~12의 미션을 **마이크로비트 + AI 브리지**로 재구성
- 연계 교과: 실과(소프트웨어·로봇), 도덕(정보 윤리), 사회(사회적 약자·공동체)
  ※ 성취기준 코드는 학교 교육과정(2015/2022 개정)에 맞춰 원 교안 지도안의 표기를 확인해 적용하세요.

## 전체 흐름

| 블록 | 문제해결 단계 | 주제 | 코딩 개념 | 예제 |
|---|---|---|---|---|
| 1-2 | 문제 이해 | 로보독 만나기·문제 찾기 | 순차, 반복 | `01_hello-robodog` |
| 3-4 | 아이디어 생성 | 센서로 반응하는 로봇 | 변수, 조건, 회전 | `02_distance-rule` |
| 5-6 | 아이디어 선택·설계 | AI로 보는 로봇 + AI 윤리 | 데이터, 학습, 라디오, 함수 | `03_ai-traffic-dog` |
| 7-8 | 개발·공유 | 모둠 AI 로보독 프로젝트 | 종합, 디버깅 | `04_ai-team-template` |

## 1-2차시: 문제 이해 — "로보독, 너는 누구니?"

**목표**: 피지컬 AI 개념을 이해하고, 로보독이 도울 수 있는 생활 속 문제를 찾는다.

| 시간 | 활동 |
|---|---|
| 10분 | 로봇 안전 서약서 작성(떨어뜨리지 않기, 속도 30 이하, 비상정지 A버튼) — 서울대 1차시 활동지 활용 |
| 15분 | 피지컬 AI 이야기: 센서(눈) → AI(뇌) → 모터(몸). 로보독 부품 찾기 |
| 10분 | 로보독 이름 짓기, MakeCode 확장 `kocoafab/robodog` 추가 |
| 25분 | 순차 코딩: 표정·소리·자세로 "자기소개 장면" 만들기 → 반복으로 3번 인사 |
| 15분 | **문제 카드** 4영역(환경·사회적 약자·정서·재난)에서 고르기 → 2×2 매트릭스(중요성×해결가능성) |
| 5분 | 모둠 문제 정의 한 문장: "○○한 사람이 △△ 때 어려움을 겪는다." |

산출물: 안전 서약서, 문제 정의 활동지

## 3-4차시: 아이디어 생성 — "규칙으로 반응하는 로봇"

**목표**: 센서와 조건문으로 상황에 반응하는 로보독을 만들고, 규칙 방식의 한계를 발견한다.

| 시간 | 활동 |
|---|---|
| 10분 | 센서값 관찰: 거리센서 값을 마이크로비트 화면에 표시 |
| 20분 | `02_distance-rule`: 가까우면 멈춤·경고, 멀면 전진 — 기준값을 모둠이 결정 |
| 15분 | 회전 추가: 장애물이 있으면 90° 회전 후 다시 걷기 (회전 블록) |
| 15분 | 아이디어 발산: 우리 모둠 문제를 로보독이 도우려면 **무엇을 알아봐야** 하나? |
| 15분 | 한계 토의: "신호등 색·음식 종류·물건 주인"은 거리센서 규칙으로 알 수 있을까? → AI 필요성 |

산출물: 아이디어 발산 활동지("로보독이 알아봐야 할 것" 목록)

## 5-6차시: 아이디어 선택·설계 — "AI로 보는 로봇"

**목표**: 데이터로 AI를 학습시키고, 인식 결과로 로보독을 제어하며, AI 윤리를 생각한다.

| 시간 | 활동 |
|---|---|
| 10분 | AI는 어떻게 배울까? 지도학습 = "정답 붙은 예시 보여 주기" (원 교안 CH10 개념) |
| 20분 | **AI 신호등 안내견**: AI 브리지로 빨강·노랑·초록·배경 학습 → `03_ai-traffic-dog`로 정지/대기/출발 |
| 15분 | 데이터 실험: 사진 수·조명·비슷한 색(주황)을 바꿔 확신도 변화 기록 → **데이터 편향** 발견 |
| 15분 | AI 윤리 토의: ① 얼굴 사진은 개인정보 ② AI가 틀리면 누가 책임? (Human-in-the-loop) ③ 모두에게 공평한가? |
| 15분 | 모둠 해결안 설계: "AI가 보는 것(카드 1~3) → 로보독 행동" 설계표 + 코드 스케치 3질문(순서·블록·구조) |

산출물: 데이터 실험 기록지, 해결안 설계표

설계표 예시

| 번호 | AI가 보는 것 | 로보독 행동 | 왜? |
|---|---|---|---|
| 1 | 땅콩 그림 카드 | 빨간 몸통 + 으르렁 + 뒤로 물러서기 | 알레르기 경고 |
| 2 | 우유 그림 카드 | 노란 몸통 + 기다려 소리 | 확인 필요 |
| 3 | 안전한 음식 카드 | 초록 몸통 + 인사 | 먹어도 됨 |
| 4 | 배경 | 준비 자세 | 아무것도 없음 |

## 7-8차시: 개발·공유 — "우리 모둠 AI 로보독"

**목표**: 설계한 해결안을 구현·디버깅하고, 결과를 공유·성찰한다.

| 시간 | 활동 |
|---|---|
| 30분 | 구현: 모둠 카드 학습 → `04_ai-team-template` TODO 채우기 → 시험 |
| 15분 | 디버깅: "AI가 틀린 건가, 코드가 틀린 건가?" 구분하기 (브리지 화면 번호 vs 로보독 행동 비교) |
| 20분 | 공유: 1가고 1남기(한 명은 설명, 나머지는 다른 모둠 체험) + 패들렛 동료평가 |
| 15분 | 성찰: 우리 AI 로보독이 틀렸던 순간, 고친 방법, 실제로 쓰려면 더 필요한 것 |

모둠 프로젝트 주제 예시 (원 교안 미션의 초등·마이크로비트 버전)

| 주제 | 원 교안 | AI가 볼 것 | 개인정보 |
|---|---|---|---|
| 신호등 안내견 | CH10 색상인식 | 색 카드 | 안전 |
| 급식 알레르기 탐지견 | CH12 QR인식 | 음식 그림 카드 | 안전 |
| 내 물건 알아보는 반려견 | CH11 얼굴인식 | 얼굴 **대신** 필통·배지 | 안전 |
| 교실 도우미견 | 신규 | 손 모양(조용히·정리) | 손만 촬영 |

## 평가 계획

| 영역 | 평가 요소 | 방법 | 시기 |
|---|---|---|---|
| 지식 | 피지컬 AI 구성, 규칙 vs 학습 차이 | 활동지 서술 | 4, 6차시 |
| 기능 | 조건·라디오·함수를 이용한 제어 | 교사 관찰 체크리스트(◎○△) | 4, 8차시 |
| 기능 | 데이터 수집·개선(확신도 기록) | 데이터 실험 기록지 | 6차시 |
| 태도 | 안전·개인정보·협력 | 자기평가(별점) + 동료평가(패들렛) | 8차시 |

산출물 루브릭(모둠 프로젝트)

| 기준 | 3점 | 2점 | 1점 |
|---|---|---|---|
| 문제 해결 | 정의한 문제와 로보독 행동이 분명히 연결됨 | 일부 연결됨 | 연결이 약함 |
| AI 활용 | 3종류 이상 학습, 배경 포함, 확신도 확인 | 2종류 학습 | 학습 불안정 |
| 코딩 | 모든 신호에 행동 + 비상정지 | 대부분 동작 | 일부 동작 |
| 윤리·안전 | 개인정보·오류 대처를 설명함 | 일부 고려 | 고려 없음 |

## 운영 팁

- 모둠번호(라디오 그룹)를 마이크로비트·PC에 라벨로 붙여 두면 혼선이 없습니다.
- AI 브리지 화면의 번호가 맞는데 로보독이 다르게 움직이면 → 코드 문제, 화면 번호부터 틀리면 → 데이터 문제.
- 수업이 끝나면 각 PC에서 '모두 지우기'로 학습 데이터를 지우세요(새로고침해도 지워짐).
- 로보독 카메라(코코블록·스크래치)로 하는 AI 활동을 함께 보여 주고 싶다면, 원 교안 스크래치 AI CH10~12를 교사 시연용으로 쓰세요.
