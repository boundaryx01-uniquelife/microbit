# 8차시 전체형 — "로보독과 함께하는 피지컬 AI 문제해결"

- 대상: 초등 5~6학년 (중·고는 `06_중고등_확장안.md` 참고)
- 시간: 8차시 = 2차시 연속 블록(80분) × 4회
- 바탕 자료: 코코아팹×서울대 8차시(창의적 문제해결 4단계 틀, 활동·평가 구조)
  + 스크래치 인공지능 교안 CH10~12 미션을 **마이크로비트 + AI 브리지**로 재구성
- 연계 교과: 실과(소프트웨어·로봇), 도덕(정보 윤리), 사회(공동체·사회적 약자)
  ※ 2026학년도 초5~6은 2022 개정 교육과정 적용 학년입니다.

성취기준 연결: 실과 **[6실04-06]**(로봇에 코딩·프로그램 적용), **[6실05-03]**(실생활 문제를 해결하는 프로그램을 협력하여 작성하고 공유), **[6실05-04]**(인공지능에 활용할 데이터 탐색), **[6실05-05]**(인공지능이 만들어지는 과정 체험·사회적 영향 탐색). 문제해결 프로젝트(1~8차시) 전체가 [6실05-03], AI 학습·실험(3~6차시)이 [6실05-04]·[6실05-05], 로보독 코딩(5~6차시)이 [6실04-06]에 해당합니다. 도덕(정보 윤리)·사회 성취기준은 학교 교육과정에 맞춰 덧붙이세요.
※ 성취기준 코드·문구는 교육부 고시 제2022-33호 「초등학교 교육과정」을 옮긴 2차 자료 두 곳에서 확인했습니다(2026-11-07). 지도안에 쓰기 전에 고시 원문과 한 번 더 대조하세요.
    (원 교안 지도안의 코드는 확인용 참고).
- 모든 블록: **앞 5분 배부·연결, 뒤 5분 정리·회수**를 시간에 포함했습니다.

## 1-2차시: 문제 이해 — "로보독, 너는 누구니?" (80분)

**목표**: 피지컬 AI 개념을 이해하고, 로보독이 도울 수 있는 생활 속 문제를 찾는다.

| 시간 | 활동 |
|---|---|
| 5분 | 배부·전원 |
| 8분 | 로봇 안전 서약서 작성(떨어뜨리지 않기, 속도 30 이하, 위험하면 멈춤, 얼굴 찍지 않기) |
| 12분 | 피지컬 AI 이야기: 센서(눈) → AI(뇌) → 모터(몸). 로보독 부품 찾기 |
| 8분 | 로보독 이름 짓기, MakeCode 확장 `kocoafab/robodog` 추가(전체 입력) |
| 25분 | 순차 코딩: 표정·소리·자세로 "자기소개 장면" → 반복 블록으로 3번 인사 |
| 17분 | 문제 카드 4영역(환경·사회적 약자·정서·재난) 고르기 → 2×2 매트릭스(중요성×해결 가능성) → 문제 정의 한 문장 |
| 5분 | 정리·회수 |

## 3-4차시: 아이디어 생성 — "규칙으로 반응하는 로봇" (80분)

**목표**: 센서와 조건문으로 상황에 반응하는 로보독을 만들고, 규칙 방식의 한계를 발견한다.

| 시간 | 활동 |
|---|---|
| 5분 | 배부·`02_distance-rule` 넣기 |
| 10분 | 센서값 관찰: A 버튼으로 거리 값 보기(로봇은 움직이지 않음) |
| 20분 | 기준값 정하기 → B 버튼으로 걷기 시작/멈춤 → 가까우면 멈춤·경고 확인 |
| 12분 | 확장(선택): 가까우면 멈춘 뒤 `회전` 블록으로 90° 돌아서 다시 걷기 |
| 13분 | 아이디어 발산: 우리 모둠 문제를 돕기 위해 로보독이 **무엇을 알아봐야** 하나? (활동지 E) |
| 15분 | 한계 토의: "땅콩 그림·내 필통·위험 표지"를 거리센서 규칙으로 알 수 있을까? → AI 필요성. (색은 색값 규칙으로도 가능하다는 의견이 나오면 인정하고 그림·물건으로 넘어가기) |
| 5분 | 정리·회수 |

## 5-6차시: 아이디어 선택·설계 — "AI로 보는 로봇" (80분)

**목표**: 예시 데이터로 AI를 학습시키고, 인식 결과로 로보독을 제어하며, AI의 한계와 윤리를 생각한다.

| 시간 | 활동 |
|---|---|
| 5분 | 배부·연결(로보독 03, PC USB 마이크로비트), AI 브리지 열기 |
| 8분 | AI는 어떻게 배울까? **"정답 이름표가 붙은 예시를 보여 주기"**(지도학습). AI 브리지는 새 사진을 모아 둔 예시들과 비교해 **가장 비슷한 것들의 이름**으로 답한다 |
| 17분 | **AI 신호등 안내견**: 빨강·노랑·초록·배경 학습 → 정지/대기/출발. ■ 멈춤 연습 |
| 15분 | 데이터 실험(활동지 A): 주황 카드·가리기·어둡게 → 확신과 답 기록. "**자신 있게 틀릴 수 있다**" 발견 |
| 15분 | AI 윤리 토의: ① 얼굴 사진은 개인정보 ② AI가 틀리면 누가 확인·책임? (사람이 최종 확인 = Human-in-the-loop) ③ 한 사람 손·한 조명에서만 모은 데이터는 다른 교실에서도 잘 될까? (데이터 치우침) |
| 15분 | 모둠 해결안 설계표(활동지 C) + 코드 스케치 3질문(순서·블록·구조) |
| 5분 | 정리·회수·'모두 지우기' |

설계표 예시

| 번호 | AI가 보는 것 | 로보독 행동 | 왜? |
|---|---|---|---|
| 1 | 땅콩 그림 카드 | 빨간 몸통 + 으르렁 + 멈춤 | 알레르기 경고 |
| 2 | 우유 그림 카드 | 노란 몸통 + 기다려 소리 | 확인 필요 |
| 3 | 안전한 음식 카드 | 초록 몸통 + 인사 | 먹어도 됨 |
| 4 | 배경 | 준비 자세 | 아무것도 없음 |

## 7-8차시: 개발·공유 — "우리 모둠 AI 로보독" (80분)

**목표**: 설계한 해결안을 구현·디버깅하고, 결과를 공유·성찰한다.

| 시간 | 활동 |
|---|---|
| 5분 | 배부·연결 |
| 30분 | 구현: 모둠 카드 학습 → `04_ai-team-template` TODO 채우기 → 시험 |
| 10분 | 디버깅: "AI가 틀린 건가, 코드가 틀린 건가?" — 브리지 화면 '지금 보내는 번호'와 로보독 마이크로비트 화면 숫자 비교 |
| 20분 | 공유: 1가고 1남기(한 명은 설명, 나머지는 다른 모둠 체험) + 칭찬 쪽지(종이 갤러리 워크) |
| 10분 | 성찰(활동지 F): 틀렸던 순간, 고친 방법, 실제로 쓰려면 더 필요한 것 |
| 5분 | 정리·회수·학습 데이터 '모두 지우기' |

모둠 프로젝트 주제 (원 교안 미션의 초등·마이크로비트 버전)

| 주제 | 원 교안 | AI가 볼 것 | 개인정보 |
|---|---|---|---|
| 신호등 안내견 | 스크래치 AI CH10 색상인식 | 색 카드 | 안전 |
| 급식 알레르기 탐지견 | CH12 QR인식 | 음식 그림 카드 | 안전 |
| 내 물건 알아보는 반려견 | CH11 얼굴인식 | 얼굴 **대신** 필통·배지 | 안전 |
| 교실 도우미견 | 신규 | 손 모양(손만 촬영) | 얼굴이 나오지 않게 |

## 운영 팁

- 모둠번호(라디오 그룹)를 마이크로비트·PC에 라벨로 붙이세요. 라디오 그룹은 혼선 방지용일 뿐 보안 장치가 아닙니다.
- 브리지 화면의 번호가 맞는데 로보독이 다르게 움직이면 → 코드 문제, 화면 번호부터 틀리면 → 데이터 문제.
- 수업이 끝나면 각 PC에서 '모두 지우기'(새로고침해도 지워짐).
- 로보독 자체 AI 카메라(얼굴·색상·QR)는 유선 확장(`kocoafab/robodog`)에는 블록이 없고, 공식 무선 확장(`kocoafab/robodog-radio`)에는 있습니다(예제 06~08, **실물 미검증**). 실물 점검 전에는 원 교안 스크래치 AI CH10~12를 **교사 시연용**으로 쓰세요.
- 패들렛 등 온라인 동료평가는 학교 계정·연령 정책을 확인한 뒤 쓰세요. 기본안은 종이 칭찬 쪽지입니다.
