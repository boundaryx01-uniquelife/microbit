## 로봇 안전 서약서

```
[로보독 안전 약속]                         모둠: ____  이름: ________

□ 로보독을 책상 가장자리에 두지 않고, 떨어뜨리지 않겠습니다.
□ 로보독 속도는 30 이하로 정하겠습니다.
□ 위험하면 바로 멈춤(■ 멈춤 버튼 / 로보독 마이크로비트 A 버튼)을 누르겠습니다.
□ 카메라로 친구나 내 얼굴을 찍지 않겠습니다. 카드와 물건만 보여 주겠습니다.
□ 수업이 끝나면 AI 학습 데이터를 '모두 지우기' 하겠습니다.

                                   서명: ____________
```

## [활동지 A] AI 신호등 안내견 실험

```
[AI는 어떨 때 헷갈릴까?]                    모둠: ____  이름: ________

1. 종류마다 사진을 몇 장 모았나요?
   빨강 ___장 / 노랑 ___장 / 초록 ___장 / 배경 ___장

2. 실험 결과 (AI 답과 확신 막대를 보고 적기)
   | 실험                    | AI의 답      | 확신(막대 또는 %) | 로보독 행동 |
   |-------------------------|--------------|-------------------|-------------|
   | 빨강 카드 (기준)        |              |                   |             |
   | 주황 카드 (처음 보는 색)|              |                   |             |
   | 카드를 손으로 반쯤 가림 |              |                   |             |
   | 어둡게 함               |              |                   |             |

3. AI가 확신이 높은데도 틀린 적이 있나요?  예 / 아니요
   있다면 무엇을 무엇이라고 했나요? ______________________

4. 진짜 길에서 로봇 안내견이 틀린다면 어떤 일이 생길까요?
   ____________________________________________

5. AI를 더 믿을 수 있게 하려면? (데이터, 멈춤 장치, 사람 확인 중 골라 쓰기)
   ____________________________________________
```

교사용 예상 결과: 주황 카드는 빨강·노랑으로 **높은 확신의 오답**이 자주 나옵니다(정답 없음 — 관찰이 목적).

## 교사 관찰 체크리스트 (판단 기준 포함)

### 소개형(2차시)

| 문항 | ◎ 잘함 | ○ 보통 | △ 노력 필요 |
|---|---|---|---|
| 학습 데이터를 모았다 | 4종류를 고르게 20장 이상, 각도·위치를 바꿔 모음 | 4종류를 모았으나 수·다양성이 부족 | 도움을 받아 일부만 모음 |
| AI가 틀리는 이유를 말했다 | 예시(데이터)와 다른 입력이면 자신 있게도 틀린다고 설명 | "헷갈려서" 수준으로 말함 | 이유를 말하지 못함 |
| 안전 규칙을 지켰다 | 멈춤 장치를 스스로 사용, 속도·위치 규칙 준수 | 안내 후 지킴 | 반복 안내 필요 |

### 기본형(4차시)·전체형 공통

| 문항 | ◎ 잘함 | ○ 보통 | △ 노력 필요 |
|---|---|---|---|
| 규칙 vs AI 차이 설명 | 두 방식 모두 사람의 선택(기준값/예시·이름표)이 들어감을 포함해 설명 | 한쪽 특징만 설명 | 차이를 말하지 못함 |
| 조건문·라디오로 제어 | 모든 번호에 행동을 정하고 멈춤 장치를 유지 | 대부분 동작 | 예제를 그대로 사용 |
| 데이터 개선 | 실험 결과를 보고 데이터를 바꿔 다시 확인 | 실험만 함 | 실험 기록 미흡 |
| 윤리·안전 | 얼굴 미촬영, 오류 시 멈춤·사람 확인을 설계에 반영 | 안내받아 반영 | 고려하지 않음 |

### 모둠 프로젝트 루브릭(전체형 8차시)

| 기준 | 3점 | 2점 | 1점 |
|---|---|---|---|
| 문제 해결 | 정의한 문제와 로보독 행동이 분명히 연결됨 | 일부 연결됨 | 연결이 약함 |
| AI 활용 | 3종류 이상 + 배경 학습, 실험으로 개선 | 2종류 학습 | 학습이 불안정 |
| 코딩 | 모든 번호에 행동 + 안전장치 유지 | 대부분 동작 | 일부 동작 |
| 윤리·안전 | 개인정보·오류 대처를 설명함 | 일부 고려 | 고려 없음 |
