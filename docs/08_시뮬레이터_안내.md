# 로보독 시뮬레이터 안내

주소: **https://microbit-bridge.netlify.app/sim/**

로보독이 없어도, 또는 실물에 내려받기 전에, **MakeCode로 짠 코드대로 로보독이 어떻게 움직이는지** 2D·3D로 미리 봅니다.

> 코코아팹과 협력해 만든 도구입니다. 다리 움직임 계산은 코코아팹의 "로보독 다리 시뮬레이션"(edu.kocoafab.cc/robodog-simul) 자료를 바탕으로 합니다.

## 쓰는 법

처음 화면은 **🧩 블록 코딩(MakeCode 편집기)**입니다. 코딩 칸을 넓게 쓰도록 오른쪽 로보독 칸은 좁고(스크롤해도 따라옴), **예제 자동 시연** 카드는 접혀 있습니다(펼치면 카드 선택).
로보독 화면은 **3D 보기**가 기본입니다(가벼운 2D는 [2D 보기] 탭, 또는 주소 끝 `?view=2d`). 코딩 칸과 로보독 칸 사이의 **세로 막대를 끌면 폭**이 바뀌고(화살표 키도 됨, 두 번 누르면 원래대로, 다음에 열어도 유지), 블록 크기는 MakeCode 편집기 오른쪽 아래 **＋ / －**로 바꿉니다.
블록 코딩 화면에서는 시연이 저절로 시작하지 않습니다. 주소 끝 `?demo=1` 이면 "동작 둘러보기" 시연이 저절로 시작합니다(첫 화면의 "예제 시연부터 보기" 링크). 시연 중에는 자막과 [시연 멈추기]가 보이고, 아무 버튼이나 직접 누르면 멈춥니다.

1. **① 말로 만들기**(맨 위 한 줄): 하고 싶은 일을 한국어로 적고 [코드 만들기](또는 Enter) → 설명·주의할 점이 나옵니다(코드는 [만든 코드 보기]). [예시 문장]을 누르면 예시가 입력됩니다.
   [▶ 시뮬레이터에서 실행]으로 먼저 보고, [🧩 이 코드로 바꾸기]를 누르면 블록 코딩 편집기에 블록으로 들어갑니다. 자세한 내용은 아래 "로보독 도우미".
2. **🧩 블록 코딩 (MakeCode)**: 진짜 MakeCode 편집기가 시뮬레이터 안에 열립니다.
   - 로보독 확장이 미리 들어 있어 왼쪽 메뉴의 **로보독** 블록을 바로 끌어다 쓸 수 있습니다(무선 확장 코드면 `robodog-radio`가 들어감).
   - **블록을 고치면 약 1초 뒤 시뮬레이터 로보독이 그 코드로 다시 움직입니다**('블록을 고치면 바로 실행' 체크).
   - 예제·시연·도우미 코드로 바꾸면 그 코드가 편집기로 들어갑니다. 마이크로비트에 넣으려면 편집기 아래 **[다운로드]**.
   - MakeCode 공식 삽입 방식(controller 모드)을 쓰며 `makecode.microbit.org` 접속이 필요합니다.
     확장은 시험한 버전으로 고정(유선 331dd39, 무선 4a50d45). 프로젝트는 MakeCode 계정이 아니라 이 화면(브라우저)에 저장됩니다.
3. **글자 코드 (JavaScript)**: 학교망에서 MakeCode가 열리지 않으면(60초 뒤 자동 전환) 이 탭에 코드를 붙여넣고 **▶ 실행**. 실행 결과·오류는 [▶ 실행] 옆에 바로 표시됩니다.
   예제 목록에서 고르면 "지금 코드를 예제로 바꿀까요?" 확인 창이 뜹니다(지금 코드가 지워지므로).
4. 오른쪽 **③ 버튼 눌러 시험하기 · 라디오 · 센서 · 환경**(접기 가능): 마이크로비트 A·B, 라디오 숫자 0~9, **로보독 본체 버튼 누르기**, 장애물·책상/바닥.
   실물 로보독에 꽂은 마이크로비트의 A·B는 가려져 누를 수 없습니다(패널에도 경고가 있음). 수업 예제 01~05와 시연은 **본체 버튼 누르기**로 동작합니다.
   **라디오 숫자 버튼은 한 번 누르면 한 번만 보냅니다.** 예제 3처럼 2초 동안 신호가 없으면 멈추는 코드는 **[마지막 숫자 계속 보내기]**를 켜거나 같은 컴퓨터의 AI 브리지를 쓰세요.
5. **2D 보기**: 위에서 본 책상(경로·거리센서 빔·장애물) + 옆모습(다리 자세) + 눈 LED / **3D 보기**: 마우스로 돌려 보기·확대.
6. **↺ 처음으로**: 로보독을 처음 자리로. **■ 정지**: 코드 멈춤.

예제 목록에서 수업 예제 1~5와 '동작 둘러보기'를 불러올 수 있습니다(시연 카드에는 8대 군무가 하나 더 있음). 무선 예제 06~08은 수업 자료 페이지에서 내려받아 붙여넣으면 실행됩니다(카메라 AI 값은 늘 "인식 없음").

## 로보독 도우미 (말로 코드 만들기)

| | 🤖 AI 도우미 (Claude) | 📘 규칙 도우미 |
|---|---|---|
| 언제 | 사이트에 Claude API 키를 설정했을 때 | 키가 없거나 AI 연결이 안 될 때(자동 전환) |
| 알아듣는 말 | 자유로운 문장, "지금 코드 고치기" 가능 | 정해진 표현만 (아래) |
| 비용·인터넷 | 요청마다 API 요금(선생님 계정) | 무료, 브라우저 안에서만 동작 |

**규칙 도우미가 알아듣는 표현**
- 언제: `A 버튼을 누르면`(`a누르면`도 됨), `B 버튼을 누르면`, `A+B 버튼을 누르면`, `로보독 버튼을 누르면`(실물의 본체 버튼, 계속 걷기 켜기/끄기와 멈춤 잠금도 이 버튼 사용), `라디오 3을 받으면`, `장애물이 가까우면 … 아니면 …`, `계속`, `3번 반복`
  (어느 버튼인지 없으면 코드를 만들지 않고 다시 물어봅니다. "A 버튼"이라고 말하면 A로 만들되, 실물 로보독에서는 A·B가 가려진다는 경고를 함께 보여 줍니다)
- 무엇을: `앞으로/뒤로 2초 (천천히·빠르게·속도 20)`, `오른쪽/왼쪽으로 90도 돌아`, `오른쪽으로 걸어`(돌고 걷기), `한 바퀴`, `뒤로 돌아`(180°), `앉아·누워·인사·손 흔들어·물구나무·기지개·일어서`, `몸을 낮게/높게`, `점프`(흉내), `멈춰`, `춤춰`
- 소리: `멍멍 짖어`, `으르렁`, `"안녕/기다려/비켜/출발"이라고 말해`, `도레미 노래` / 불빛: `빨간·초록·파란… 불 켜`, `불 꺼`, `무지개`
- 표정: `하트 눈`, `웃는 눈`, `눈 감아`, `슬픈 표정`, `화난 눈`, `초롱초롱`, `큰 눈`, `깜박` / 화면: `마이크로비트에 하트`, `마이크로비트에 거리`
  설명에는 MakeCode 블록 메뉴의 공식 이름을 씁니다(예: 하트 눈 → 표정 [ILOVEYOU], 웃는 눈 → [감사], 화난 눈 → [찢눈]; 모양은 이름으로 추정).
- 문장은 `하고`, `한 다음`, 쉼표로 이어 말하면 순서대로 들어갑니다. 모르는 말은 "이해하지 못한 말"로 알려 주고 할 수 있는 말과 비슷한 예제를 추천합니다.

**도우미가 지키는 안전 규칙(규칙·AI 공통)**: 속도 30 이하(더 빠르게 말해도 30) · 계속 걷기는 로보독 본체 버튼으로 켜고 끄며 10초 뒤 저절로 멈춤 · 거리 규칙은 값 0(못 읽음)이면 멈추고 상태가 바뀔 때만 명령 · 거리센서는 앞만 보므로 뒤로 계속 걷기는 넣지 않음 · 라디오 규칙은 2초 동안 신호가 없으면 멈추고 본체 버튼 = 멈춤 잠금 ↔ 풀기.
거리센서는 **책상 끝(낭떠러지)을 감지하지 못합니다.** 계속 걷는 코드는 바닥이나 울타리 안에서 시험하세요.

**AI 도우미 켜기 (선생님·관리자)** — 키는 채팅·코드·화면에 절대 넣지 말고 Netlify에만 넣습니다.
1. Netlify → 사이트 → **Site configuration → Environment variables**
2. `ANTHROPIC_API_KEY` = Claude API 키 (console.anthropic.com에서 발급)
3. `ASSISTANT_CLASS_CODE` = 수업 코드(예: 6자리 이상 권장) — **필수입니다.** 넣지 않으면 AI 도우미가 켜지지 않고 규칙 도우미만 동작합니다. 학생은 도우미 칸의 **수업 코드**에 이 코드를 넣어야 AI 도우미를 쓸 수 있고, 코드를 넣기 전에는 규칙 도우미가 대신합니다. 학생에게는 수업 시간에만 알려 주세요. 짧은 숫자 코드는 알아맞히기 쉬우니 길게 정하세요(같은 IP에서 5번 틀리면 10분 막히지만 완전한 방어는 아닙니다).
4. (선택) `ROBODOG_MODEL` = 모델 이름(기본 `claude-sonnet-5-5`: 실측 약 6초에 응답). Netlify 함수는 약 10초 안에 답해야 해서, 더 큰 모델은 시간 초과가 날 수 있습니다(시간 초과·오류 때는 규칙 도우미로 자동 전환).
   비용: 요청 1번에 입력 약 3천 토큰(고정 안내문) + 출력 약 600 토큰. 정확한 금액은 Anthropic 요금표로 계산하고, console.anthropic.com에서 **월 사용 한도**를 꼭 정해 두세요.
5. 다시 배포(Deploys → Trigger deploy)하면 수업 코드를 넣은 화면의 도우미 배지가 **AI 도우미 (Claude)**로 바뀝니다(코드를 넣기 전에는 "규칙 도우미 · AI는 수업 코드가 있어야 켜져요").

안전장치: 키는 서버 함수(`netlify/functions/robodog-assistant.mjs`)에만 있고 브라우저로 가지 않음 · 수업 코드가 없으면 AI 꺼짐, 코드를 모르면 사용 불가(서버에서 확인) · 코드 5번 틀리면 10분 잠금 · 요청 600자 제한 · 같은 IP 1분 6회 제한 · 로보독과 관계없는 요청은 거절 안내 · 책상 속도 30 이하 규칙 · 만든 코드는 실행 전에 문법 검사.
주의: AI가 만든 코드도 틀릴 수 있습니다. 시뮬레이터에서 먼저 보고, 실물은 낮은 속도로 시험하세요. 학생 입력은 Anthropic 서버로 전송됩니다(개인정보를 적지 않도록 지도).

## 군무 시연 (8대)

예제 카드 **🐕×8 군무**를 누르면 로보독 8대(2줄×4대)가 바닥에서 함께 춤을 춥니다. 3D 보기로 보면 더 실감 납니다.

| 순서 | 동작 | 여러 대 제어 방식(파이썬 공식 라이브러리 함수) |
|---|---|---|
| 1 | 준비 자세 | `multi_gesture(dogs, STANDUP)` — 동시에 |
| 2 | 바운스: 낮게↔높게 6번 | `multi_leg_bend` — 동시에 |
| 3 | 웨이브: 왼쪽부터 차례로 일어나고 앉기 | `*_sequential` 계열처럼 차례로(파이썬 0.2.0에는 다리 높이용 sequential 함수가 없어 `multi_leg_bend`를 간격 두고 반복하는 **개념 예시**) |
| 4 | 불빛 웨이브: 몸통 LED 무지개 | `multi_bodyLED_sequential` |
| 5 | 표정 웨이브: ILOVEYOU → 감사 | `multi_headLEDExp_sequential` (파이썬 상수 이름은 `ILOVEU`) |
| 6 | 다 함께 반 바퀴 회전, 다시 반대로 | `multi_rotate` |
| 7 | 물구나무 | `multi_gesture(dogs, HEADSTAND)` |
| 8 | 차례로 인사 + 멍멍 | `multi_gesture_sequential(dogs, 0.2, …, GREETING)` |

- 실제 군무는 마이크로비트 1대 코드가 아니라, PC가 USB 동글로 여러 대에 명령을 보내는 **파이썬 `multi_*` 함수** 방식입니다(공식 API 문서 기준).
  시연 중 코드 칸에 그 흐름을 주석으로 보여 줍니다.
- 수업 활용: "동시에(multi_*)"와 "차례로(*_sequential, 간격·순서)"의 차이를 눈으로 비교하고, 모둠별 안무 순서를 짜 보는 활동에 쓸 수 있습니다.
- 동작 시간·간격·안무 순서는 시연용으로 정한 값이며, 영상 속 실제 안무와 같지는 않습니다.

## 실물과 다른 점 (꼭 읽어 주세요)

| 항목 | 시뮬레이터 | 비고 |
|---|---|---|
| 걷는 속도 | 속도 100 ≈ 15cm/초 | **추정치**. 실물 측정 후 `sim/runtime.js`의 `EST` 값 조정 |
| 회전 빠르기 | 빠르기 100 ≈ 120°/초 | 추정치 |
| 다리 높이·발끝 → 관절 각도 | **코코아팹 공식 다리 시뮬레이터의 실측 표본 125개 + 보간식 그대로** | 공식 값 (아래 "공식 자료 반영" 참고) |
| 몸·다리 비율 | 공식 측면도 비율(몸통 270, 윗다리 92, 아랫다리 109, 머리 60×112 px) | 비율은 공식, cm 축척(0.045cm/px)은 추정 → 몸통 약 12cm |
