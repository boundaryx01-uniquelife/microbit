# 로보독 시뮬레이터 안내

주소: **https://microbit-bridge.netlify.app/sim/**

로보독이 없어도, 또는 실물에 내려받기 전에, **MakeCode로 짠 코드대로 로보독이 어떻게 움직이는지** 2D·3D로 미리 봅니다.

## 쓰는 법

0. 처음 화면은 **🧩 블록 코딩(MakeCode 편집기)**입니다. 코딩 칸을 넓게 쓰도록 오른쪽 로보독 칸은 좁고, **예제 자동 시연** 카드는 접혀 있습니다(펼치면 카드 선택).
   시연 중에는 자막과 [시연 멈추기]만 보입니다. 처음 열면 "동작 둘러보기" 시연이 저절로 시작합니다(`?demo=0`이면 끔).
1. **🤖 로보독 도우미**(맨 위): 하고 싶은 일을 한국어로 적고 [코드 만들기] → 코드·설명·주의할 점이 나옵니다.
   [▶ 시뮬레이터에서 실행]으로 먼저 보고, [🧩 이 코드로 바꾸기]를 누르면 블록 코딩 편집기에 블록으로 들어갑니다. 자세한 내용은 아래 "로보독 도우미".
2. **🧩 블록 코딩 (MakeCode)**: 진짜 MakeCode 편집기가 시뮬레이터 안에 열립니다.
   - 로보독 확장이 미리 들어 있어 왼쪽 메뉴의 **로보독** 블록을 바로 끌어다 쓸 수 있습니다(무선 확장 코드면 `robodog-radio`가 들어감).
   - **블록을 고치면 약 1초 뒤 시뮬레이터 로보독이 그 코드로 다시 움직입니다**('블록을 고치면 바로 실행' 체크).
   - 예제·시연·도우미 코드로 바꾸면 그 코드가 편집기로 들어갑니다. 마이크로비트에 넣으려면 편집기 아래 **[다운로드]**.
   - MakeCode 공식 삽입 방식(controller 모드)을 쓰며 `makecode.microbit.org` 접속이 필요합니다.
     확장은 시험한 버전으로 고정(유선 331dd39, 무선 4a50d45). 프로젝트는 MakeCode 계정이 아니라 이 화면(브라우저)에 저장됩니다.
3. **JavaScript (인터넷이 안 될 때)**: 학교망에서 MakeCode가 열리지 않으면(60초 뒤 자동 전환) 이 탭에 코드를 붙여넣고 **▶ 실행**.
4. 오른쪽 **버튼 · 라디오 · 센서 · 환경**(접기 가능): 마이크로비트 A·B, 라디오 숫자 0~9, 로보독 버튼, 장애물·책상/바닥.
5. **2D 보기**: 위에서 본 책상(경로·거리센서 빔·장애물) + 옆모습(다리 자세) + 눈 LED / **3D 보기**: 마우스로 돌려 보기·확대.
6. **↺ 처음으로**: 로보독을 처음 자리로. **■ 정지**: 코드 멈춤.

예제 목록에서 수업 예제 1~5를 바로 불러올 수 있습니다.

## 로보독 도우미 (말로 코드 만들기)

| | 🤖 AI 도우미 (Claude) | 📘 규칙 도우미 |
|---|---|---|
| 언제 | 사이트에 Claude API 키를 설정했을 때 | 키가 없거나 AI 연결이 안 될 때(자동 전환) |
| 알아듣는 말 | 자유로운 문장, "지금 코드 고치기" 가능 | 정해진 표현만 (아래) |
| 비용·인터넷 | 요청마다 API 요금(선생님 계정) | 무료, 브라우저 안에서만 동작 |

**규칙 도우미가 알아듣는 표현**
- 언제: `A 버튼을 누르면`, `B 버튼을 누르면`, `A+B 버튼을 누르면`, `라디오 3을 받으면`, `장애물이 가까우면 … 아니면 …`, `계속`, `3번 반복`
- 무엇을: `앞으로/뒤로 2초 (천천히·빠르게·속도 20)`, `오른쪽/왼쪽으로 90도 돌아`, `한 바퀴`, `앉아·인사·물구나무·기지개·일어나`, `몸을 낮게/높게`, `멈춰`, `춤춰`
- 소리: `멍멍 짖어`, `으르렁`, `"안녕/기다려/비켜/출발"이라고 말해`, `도레미 노래` / 불빛: `빨간·초록·파란… 불 켜`, `불 꺼`, `무지개`
- 표정: `하트 눈`, `웃는 눈`, `눈 감아`, `화난 눈`, `초롱초롱`, `큰 눈`, `깜박` / 화면: `마이크로비트에 하트`, `마이크로비트에 거리`
- 문장은 `하고`, `한 다음`, 쉼표로 이어 말하면 순서대로 들어갑니다. 모르는 말은 "이해하지 못한 말"로 알려 주고 비슷한 예제를 추천합니다.

**AI 도우미 켜기 (선생님·관리자)** — 키는 채팅·코드·화면에 절대 넣지 말고 Netlify에만 넣습니다.
1. Netlify → 사이트 → **Site configuration → Environment variables**
2. `ANTHROPIC_API_KEY` = Claude API 키 (console.anthropic.com에서 발급)
3. `ASSISTANT_CLASS_CODE` = 수업 코드(예: 4자리) — **권장**. 이 코드를 아는 사람만 AI를 써서 요금을 보호합니다. 학생에게는 수업 시간에만 알려 주세요.
4. (선택) `ROBODOG_MODEL` = 모델 이름(기본 `claude-opus-5-5`). 저렴하게 쓰려면 더 작은 모델로 바꿀 수 있습니다.
5. 다시 배포(Deploys → Trigger deploy)하면 도우미 배지가 **AI 도우미 (Claude)**로 바뀝니다.

안전장치: 키는 서버 함수(`netlify/functions/robodog-assistant.mjs`)에만 있고 브라우저로 가지 않음 · 요청 600자 제한 · 같은 IP 1분 6회 제한 · 로보독과 관계없는 요청은 거절 안내 · 책상 속도 30 이하 규칙 · 만든 코드는 실행 전에 문법 검사.
주의: AI가 만든 코드도 틀릴 수 있습니다. 시뮬레이터에서 먼저 보고, 실물은 낮은 속도로 시험하세요. 학생 입력은 Anthropic 서버로 전송됩니다(개인정보를 적지 않도록 지도).

### AI 브리지와 함께 쓰기 (로보독 없이 AI 수업)

같은 컴퓨터에서 **AI 브리지**(https://microbit-bridge.netlify.app/ai.html)와 **시뮬레이터**를 각각 창으로 열면,
AI 브리지가 인식한 번호가 시뮬레이터 로보독에게 라디오처럼 전달됩니다(USB 마이크로비트 불필요).
→ 로보독이 모자라거나 수업 전 연습할 때 `03_ai-traffic-dog`로 신호등 안내견을 미리 해 볼 수 있습니다.

## 군무 시연 (8대)

예제 카드 **🐕×8 군무**를 누르면 로보독 8대(2줄×4대)가 바닥에서 함께 춤을 춥니다. 3D 보기로 보면 더 실감 납니다.

| 순서 | 동작 | 여러 대 제어 방식(파이썬 공식 라이브러리 함수) |
|---|---|---|
| 1 | 준비 자세 | `multi_gesture(dogs, STANDUP)` — 동시에 |
| 2 | 바운스: 낮게↔높게 6번 | `multi_leg_bend` — 동시에 |
| 3 | 웨이브: 왼쪽부터 차례로 일어나고 앉기 | `multi_leg_bend_sequential(dogs, 0.12, …)` — 차례로 |
| 4 | 불빛 웨이브: 몸통 LED 무지개 | `multi_bodyLED_sequential` |
| 5 | 표정 웨이브: 하트 눈 → 웃는 눈 | `multi_headLEDExp_sequential` |
| 6 | 다 함께 반 바퀴 회전, 다시 반대로 | `multi_rotate` |
| 7 | 물구나무 | `multi_gesture(dogs, HEADSTAND)` |
| 8 | 차례로 인사 + 멍멍 | `multi_gesture_sequential(dogs, 0.2, …, GREETING)` |

- 실제 군무는 마이크로비트 1대 코드가 아니라, PC가 USB 동글로 여러 대에 명령을 보내는 **파이썬 `multi_*` 함수** 방식입니다(공식 API 문서 기준).
  시연 중 코드 칸에 그 흐름을 주석으로 보여 줍니다.
- 수업 활용: "동시에(multi_*)"와 "차례로(*_sequential, 간격·순서)"의 차이를 눈으로 비교하고, 모둠별 안무 순서를 짜 보는 활동에 쓸 수 있습니다.
- 동작 시간·간격·안무 순서는 시연용으로 정한 값이며, 영상 속 실제 안무와 같지는 않습니다.

## 실물과 다른 점 (꼭 읽어 주세요)

| 항목 | 시뮬레이터 | 비고 |
|---|---|---|
| 걷는 속도 | 속도 100 ≈ 15cm/초 | **추정치**. 실물 측정 후 `sim/runtime.js`의 `EST` 값 조정 |
| 회전 빠르기 | 빠르기 100 ≈ 120°/초 | 추정치 |
| 다리 높이·발끝 → 관절 각도 | **코코아팹 공식 다리 시뮬레이터의 실측 표본 125개 + 보간식 그대로** | 공식 값 (아래 "공식 자료 반영" 참고) |
| 몸·다리 비율 | 공식 측면도 비율(몸통 270, 윗다리 92, 아랫다리 109, 머리 60×112 px) | 비율은 공식, cm 축척(0.045cm/px)은 추정 → 몸통 약 12cm |
| 겉모양 | 제품 사진 기준(검은 몸통, 넓은 머리, 하얀 8×8 LED 2개, 눈 사이 카메라, 아래 거리센서, 등의 마이크로비트) | 머리 폭·몸 폭은 추정 |
| 거리센서 | 머리 앞에서 장애물까지 cm, 없으면 255 | 실제 단위 미확인 |
| 눈 표정 모양 | '왕눈이'·'감사'는 영상 장면과 같은 모양, 나머지는 근사 그림 | 표정 번호와 영상 장면의 대응은 추정 |
| 효과음 | 비슷한 신호음 + 말풍선 | 실제 소리 아님(기본 꺼짐) |
| 자세 동작(앉기·물구나무·기지개·인사) | 공식 다리 표로 만든 근사 자세, 관절은 서보처럼 초당 450°로 이동 | 실제 펌웨어 자세 각도는 공개 자료가 없어 근사 |
| 걷는 다리 움직임 | 대각선 두 다리씩(트롯) 근사 | 실제 보행 패턴과 다를 수 있음 |
| 미끄러짐·넘어짐·배터리 | 없음(배터리는 슬라이더 값) | |
| 지원 안 되는 블록 | 음악, 게임, 핀, 가속도 등 | 실행은 되고 로그에 "지원하지 않는 블록"으로 표시 |

시뮬레이터에서 잘 되는 코드도 실물에서는 속도·거리 값이 달라질 수 있습니다. **수업 전 실물로 한 번 확인**하세요.

## 동작 원리 (교사·개발자용)

- 붙여넣은 코드를 브라우저 안에서 변환(Babel)해 실행합니다. 코드는 서버로 보내지 않습니다.
- 마이크로비트처럼 '무한 반복'과 버튼·라디오 이벤트가 동시에 실행되도록, 모든 블록 호출 사이에 차례 넘기기를 넣습니다.
  쉬기 블록이 없는 무한 반복도 화면이 멈추지 않습니다.
- 로보독 블록의 동작은 확장 `kocoafab/robodog` 2.0.1 소스(입력 범위 변환, 모드 전환 시 값 초기화, 회전 목표 방식)를 따랐습니다.
- 코드는 이 브라우저에만 저장됩니다(다른 기기와 공유되지 않음).
