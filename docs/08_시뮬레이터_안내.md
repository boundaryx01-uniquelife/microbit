# 로보독 시뮬레이터 안내

주소: **https://microbit-bridge.netlify.app/sim/**

로보독이 없어도, 또는 실물에 내려받기 전에, **MakeCode로 짠 코드대로 로보독이 어떻게 움직이는지** 2D·3D로 미리 봅니다.

## 쓰는 법

0. **처음 열면 "동작 둘러보기" 자동 시연이 저절로 시작**됩니다. 위쪽 **예제 자동 시연** 카드(동작 둘러보기, 1~4번 예제)를 누르면 그 예제 코드가 실행되고 버튼·라디오도 자동으로 눌러 주며, 화면 자막으로 지금 무슨 일이 일어나는지 알려 줍니다. [시연 멈추기]나 아무 버튼을 직접 누르면 시연이 멈춥니다. (주소 끝에 `?demo=0`을 붙이면 자동 시연 없이 열림)
1. MakeCode에서 코드를 만든 뒤 위쪽 **JavaScript** 탭을 눌러 코드를 모두 복사합니다.
2. 시뮬레이터 왼쪽 칸에 붙여넣고 **▶ 실행**.
3. 오른쪽 아래 **마이크로비트 A·B 버튼**, **라디오 숫자 0~9**, **로보독 버튼**으로 시험합니다.
4. **2D 보기**: 위에서 본 책상(경로·거리센서 빔·장애물) + 옆모습(다리 자세) + 눈 LED
   **3D 보기**: 마우스로 돌려 보기·확대, '카메라 따라가기'
5. **↺ 처음으로**: 로보독을 처음 자리로. **■ 정지**: 코드 멈춤.

예제 목록에서 수업 예제 1~5를 바로 불러올 수 있습니다.

## 할 수 있는 것

| 기능 | 내용 |
|---|---|
| 로보독 블록 전체 | 자세 5종, 보행 높이, 다리 높이·발끝, 어깨·무릎 각도, 이동, 회전, 정지, 시작방향 복귀, 눈 표정·문자·그림, 몸통 LED, 효과음, 센서 5종 |
| 마이크로비트 | 5×5 LED(숫자·글자·아이콘), A/B/A+B 버튼, 무한 반복, 일시정지, 변수·조건·반복·함수 |
| 라디오 | 숫자 받기(패널 버튼), **같은 컴퓨터의 AI 브리지 결과를 바로 받기** |
| 환경 | 책상(가장자리에서 떨어짐 경고) / 바닥(벽), 장애물 놓기(거리센서 반응) |
| 안전 학습 | 책상 밖으로 나가면 "떨어졌어요" 경고, 속도 30 초과 시 안내, '음악' 블록 사용 시 경고 |

### AI 브리지와 함께 쓰기 (로보독 없이 AI 수업)

같은 컴퓨터에서 **AI 브리지**(https://microbit-bridge.netlify.app)와 **시뮬레이터**를 각각 창으로 열면,
AI 브리지가 인식한 번호가 시뮬레이터 로보독에게 라디오처럼 전달됩니다(USB 마이크로비트 불필요).
→ 로보독이 모자라거나 수업 전 연습할 때 `03_ai-traffic-dog`로 신호등 안내견을 미리 해 볼 수 있습니다.

## 실물과 다른 점 (꼭 읽어 주세요)

| 항목 | 시뮬레이터 | 비고 |
|---|---|---|
| 걷는 속도 | 속도 100 ≈ 15cm/초 | **추정치**. 실물 측정 후 `sim/runtime.js`의 `EST` 값 조정 |
| 회전 빠르기 | 빠르기 100 ≈ 120°/초 | 추정치 |
| 다리 높이·발끝 → 관절 각도 | **코코아팹 공식 다리 시뮬레이터의 실측 표본 125개 + 보간식 그대로** | 공식 값 (아래 "공식 자료 반영" 참고) |
| 몸·다리 비율 | 공식 측면도 비율(몸통 270, 윗다리 92, 아랫다리 109, 머리 60×112 px) | 비율은 공식, cm 축척(0.045cm/px)은 추정 → 몸통 약 12cm |
| 겉모양 | 제품 사진 기준(검은 몸통, 넓은 머리, 하얀 8×8 LED 2개, 눈 사이 카메라, 아래 거리센서, 등의 마이크로비트) | 머리 폭·몸 폭은 추정 |
| 거리센서 | 머리 앞에서 장애물까지 cm, 없으면 255 | 실제 단위 미확인 |
| 눈 표정 모양 | 비슷하게 그린 근사 그림 | 실제 모양과 다를 수 있음 |
| 효과음 | 비슷한 신호음 + 말풍선 | 실제 소리 아님(기본 꺼짐) |
| 자세 동작(앉기·물구나무·기지개·인사) | 공식 다리 표로 만든 근사 자세, 관절은 서보처럼 초당 450°로 이동 | 실제 펌웨어 자세 각도는 공개 자료가 없어 근사 |
| 걷는 다리 움직임 | 대각선 두 다리씩(트롯) 근사 | 실제 보행 패턴과 다를 수 있음 |
| 미끄러짐·넘어짐·배터리 | 없음(배터리는 슬라이더 값) | |
| 지원 안 되는 블록 | 음악, 게임, 핀, 가속도 등 | 실행은 되고 로그에 "지원하지 않는 블록"으로 표시 |

시뮬레이터에서 잘 되는 코드도 실물에서는 속도·거리 값이 달라질 수 있습니다. **수업 전 실물로 한 번 확인**하세요.

## 동작 원리 (교사·개발자용)

- 붙여넣은 코드를 브라우저 안에서 변환(Babel)해 실행합니다. 코드는 서버로 보내지 않습니다.
- 마이크로비트처럼 '무한 반복'과 버튼·라디오 이벤트가 동시에 실행되도록, 모든 블록 호출 사이에 차례 넘기기를 넣습니다.
  쉬기 블록이 없는 무한 반복도 화면이 멈추지 않습니다.
- 로보독 블록의 동작은 확장 `kocoafab/robodog` 2.0.1 소스(입력 범위 변환, 모드 전환 시 값 초기화, 회전 목표 방식)를 따랐습니다.
- 코드는 이 브라우저에만 저장됩니다(다른 기기와 공유되지 않음).
