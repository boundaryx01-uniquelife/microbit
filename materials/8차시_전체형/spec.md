## docs와 달라진 점 (이 꾸러미는 아래 쪽을 따른다)
- 로보독 입력은 **본체 버튼**("로보독 버튼" 블록). 꽂은 마이크로비트의 A·B는 가려진다. docs/04 루브릭의 "A 잠금"은 **본체 버튼 멈춤 잠금**으로 읽는다(안전장치 3가지 = 2초 감시 · 본체 버튼 멈춤 잠금 · 속도 30 이하).
- docs/03의 "MakeCode 확장 `kocoafab/robodog` 추가(전체 입력)"는 하지 않는다. 시뮬레이터 블록 편집기에 로보독 확장이 이미 들어 있다.
- docs/03 7~8차시의 "로보독 마이크로비트 화면 숫자 비교"는 `04_ai-team-template` 기본 코드가 번호를 표시하지 않으므로 그대로는 안 된다. 7차시 3단계에서 학생이 "로보독 눈 LED에 글자 보이기(번호)" 블록을 넣는 방식으로 바꿨다(등에 꽂은 마이크로비트 화면은 가려질 수 있어 로보독 눈을 씀). 교사가 사전에 시뮬레이터와 실물 1대로 확인한다.
- 학생 코딩은 시뮬레이터 블록 편집기에서 하고, 실물에는 편집기 아래 [다운로드] → 데이터용 USB 케이블 → MICROBIT 드라이브 복사로 넣는다(전원을 끈 상태에서 마이크로비트를 빼고 꽂기). 시뮬레이터에서 먼저 시험하는 것을 기본으로 한다.
- 무선 예제 06~08(로보독 무선 확장, 손에 든 마이크로비트 리모컨, 내장 AI 카메라)은 **실물 미검증**이다. 필수 단계에 넣지 않았고, 교사가 실물로 직접 시험해 본 뒤 심화 활동으로만 써도 된다. 실물 점검 전에는 원 교안 스크래치 AI(CH10~12)를 교사 시연용으로 쓴다.
- 얼굴 학습은 하지 않는다. 얼굴 대신 카드·물건(필통·배지)을 쓰고, 손 모양은 손 그림 카드를 기본으로 한다(실제 손을 쓰면 손만, 얼굴이 나오지 않게).

## 실물에서 확인된 사실 (반드시 반영, 틀리면 수업이 안 됨)
- 로보독 **등에 꽂은 마이크로비트의 A·B 버튼은 가려져서 누를 수 없다.** 로보독 쪽 입력 = **본체 버튼(아래쪽 전원 스위치 옆)**.
- 마이크로비트가 로보독의 **뇌**. 빼면 로보독은 눈만 깜빡이고(대기) 아무것도 안 함.
- 배터리가 약하면 다리가 떨리거나 따로 노는 것처럼 보임 → 수업 전 충전·점검 필수.
- 충전 전용 USB 케이블이면 PC에 MICROBIT 드라이브가 안 보임 → 데이터용 케이블.
- 사이트: 시뮬레이터 https://microbit-bridge.netlify.app/sim/ , AI 브리지 https://microbit-bridge.netlify.app/ai.html
- 예제 파일(사이트 수업 자료 /docs/ 에서 내려받기):
  - `00_check-robodog`: 점검. 켜면 눈 하트, 몸통 불빛 = 배터리(초록 60%↑ / 노랑 30~60% / 빨강 30%↓), 본체 버튼마다 앉기↔서기
  - `00_bridge-receiver`: PC에 꽂는 USB 마이크로비트. 켤 때 B1(모둠번호) 표시, 그 뒤에는 받은 번호 표시. A = 멈춤 잠금, B = 풀기(손에 있으니 누를 수 있음)
  - `01_hello-robodog`: 본체 버튼을 누를 때마다 1 인사(파란 불·"안녕" 소리·인사 자세) → 2 조금 걷기(초록 불, 1초) → 3 앉기(주황 불) → 다시 1
  - `02_distance-rule`: 변수 가까움기준 = 20. 켜자마자 걷지 않음. 본체 버튼 = 걷기 시작/멈춤. 멈춰 있는 동안 몸통 불빛이 거리를 알려 줌(빨강 = 가까움, 초록 = 멂). 걷는 중 거리 값 0(못 읽음) = 멈춤 + 마이크로비트에 ?(Confused), 가까우면 멈춤·빨간 불·찢눈·"비켜" 소리, 멀면 초록 불·반짝 눈·속도 25로 걷기. 거리센서는 앞만 보며 책상 끝(낭떠러지)을 못 봄. 거리 값 단위는 실물로 확인(학생에게 cm라고 단정하지 않음).
  - `03_ai-traffic-dog`: 라디오 숫자로 행동. 1 빨강 = 멈추고 "비켜!" 소리·빨간 불·찢눈 / 2 노랑 = 멈춰서 기다림·주황 불 / 3 초록 = 천천히 출발(속도 25)·초록 불 / 0·4(배경) = 멈춤·눈 감음. **2초 동안 신호가 없으면 스스로 멈춤.** **본체 버튼 = 멈춤 잠금 ↔ 풀기(잠그면 눈에 X).** 켤 때 R1(모둠번호) 표시.
  - `04_ai-team-template`: 03과 같은 안전장치(2초 감시·본체 버튼 멈춤 잠금) + 함수 "번호에 맞게 행동하기"의 1·2·3번 안에 연습 행동(1 빨간 불+으르렁, 2 파란 불+인사, 3 초록 불+하트 눈)과 "할 일 메모". 0·4 = 기본 자세. 기본 코드는 받은 번호를 마이크로비트에 표시하지 않음.
  - `05_motion-tour`: 본체 버튼마다 자세 둘러보기 → 사각형 걷기(앞 1초·시계 방향 90° 회전 4번) → 다리 높이·다리 하나. 8차시 전체형에서는 필수 아님(심화·시연용).
- 멈추는 방법 3가지: ① AI 브리지 화면 [■ 멈춤] 또는 키보드 Esc ② 로보독 본체 버튼(멈춤 잠금) ③ 로보독 전원 스위치. (+ 자동: 신호 2초 끊기면 멈춤, 브리지 창을 내려도 멈춤)
- 확신 % 는 "맞을 확률"이 아니라 "AI가 자신 있어 하는 정도"(가까운 예시 중 같은 이름의 비율). 처음 보는 주황 카드를 노랑 100%로 답하는 것이 실제로 확인됨(assets/ai_orange.png).
- 시뮬레이터: 블록 코딩(MakeCode)이 처음 화면, 로보독 확장 포함, 블록을 고치면 약 1초 뒤 미리보기 반영, 3D/2D 보기. 예제 목록에서 수업 예제 1~5 불러오기. 오른쪽 패널의 [로보독 본체 버튼 누르기]가 실물 본체 버튼 역할. 라디오 숫자 버튼은 한 번 누르면 한 번만 보냄(2초 감시 코드는 [마지막 숫자 계속 보내기]를 켜거나 같은 컴퓨터의 AI 브리지 사용). 같은 컴퓨터에서 AI 브리지 창과 시뮬레이터 창을 함께 열면 브리지 결과가 시뮬레이터 로보독에게 라디오처럼 전달됨(USB 마이크로비트 불필요). 학교망에서 블록 편집기가 안 열리면 60초 뒤 글자 코드 탭으로 바뀜.
- 시뮬레이터는 걷는 속도·회전·거리 값이 추정이다. 수업 전 실물로 한 번 확인.
- AI 브리지: [학습 데이터 저장(.json)](사진이 아니라 숫자 특징만)·불러오기, [모두 지우기], 확신 기준 슬라이더(기본 70%), 같은 번호는 약 0.5초마다 다시 보냄.
- 로보독 마이크로비트 코드에 '음악' 블록 금지(통신 핀 P0와 겹칠 수 있음). USB 마이크로비트(00_bridge-receiver)에는 로보독 확장을 추가하지 않음.

   화면: 눈 LED(8×8 두 개)·눈 사이 카메라 ; 몸통 LED · 거리센서(머리 아래) ; 마이크로비트 자리(등) ; 본체 버튼(아래, 전원 스위치 옆) ; 전원 스위치 / 강조: 관찰지 1번: 찾으면 ✔ 하고 눈·뇌·몸 중 무엇인지 적어요 / 그림 sim_robodog3d.png

   화면: (뇌) 등에 꽂으면 프로그램대로 움직여요 ; (!) 꽂으면 A·B 버튼은 가려져요 [그래서 본체 버튼(전원 스위치 옆)을 써요] ; (쉼) 빼면 눈만 깜빡이고 쉬어요 [뇌가 없으면 로보독은 아무것도 못 해요] / 그림 story_microbit.png

9. **표** — 체험: 본체 버튼을 눌러 보세요
   화면: (1) 1번째 누르기 → 파란 불 + "안녕" 소리 + 인사 자세 ; (2) 2번째 누르기 → 초록 불 + 조금 걷기(1초) ; (3) 3번째 누르기 → 주황 불 + 앉기 ; (↻) 4번째 누르기 → 다시 1번째 인사

### 8차시 — 고치고 나누고 돌아보기 (11장)
80. **표지** — 고치고 나누고 돌아보기
   화면: 부제 "피지컬 AI 교실 · 전체형 8차시" / 그림 story_hello.png

   화면: 틀렸을 때 AI 문제인지 코드 문제인지 찾아 고쳐요 ; 우리 모둠의 해결안을 발표하고 다른 모둠 것을 체험해요 ; 내가 한 일을 돌아보고 성찰 글을 써요
   노트: [배부·연결 2'] 진행: 오늘 평가: 모둠 프로젝트 루브릭(8차시), 교사 관찰 체크리스트, 활동지 F, 자기·동료 평가.

- 윤리·안전 — ◎ 얼굴 미촬영, 오류 시 멈춤·사람 확인을 설계에 반영 / ○ 안내받아 반영 / △ 고려하지 않음
- (5차시 보조) 학습 데이터를 모았다 — ◎ 4종류를 고르게 20장 이상, 각도·위치를 바꿔 모음 / ○ 4종류 모았으나 수·다양성 부족 / △ 도움받아 일부만

## D. 인쇄용 준비물 (워드, A4) — 파일: 인쇄용_준비물.docx
컬러 인쇄 필수(교사용 진행표 1쪽에 안내). 8모둠이면 카드류는 학급 수에 맞춰 1~2부.

1~4쪽 **색 카드** — A4 한 장에 A6 카드 4장(2×2, 자르는 점선). 카드 = 흰 바탕 + 큰 원(지름 약 7cm) + 아래 작은 글씨(빨강/노랑/초록/주황). 1쪽 빨강 4장, 2쪽 노랑 4장, 3쪽 초록 4장, 4쪽 주황 4장. (5차시 신호등 안내견·실험용. 주황은 실험 1장씩.)
5쪽 **모둠번호 라벨** — 모둠 1~8, 모둠마다 4칸: "로보독 R1" / "PC용 B1" / "03용 R1" / "04용 R1" 식(번호만 바꿈). 큰 글씨, 자르는 선. 따로 "로보독 이름: ______" 칸 1개(1차시 이름 짓기).
6쪽 **안전 포스터** (교실 게시) — 제목 "로보독 안전 약속", 큰 글씨 3줄(떨어뜨리지 않기 · 천천히(속도 30 이하) · 위험하면 바로 멈추기), 아래 "멈추는 방법" 3칸 아이콘+글: ■ 화면 멈춤/Esc · 본체 버튼(눈에 X) · 전원 스위치. 작은 글씨: 신호가 2초 끊기면 로보독이 스스로 멈춰요.
7~8쪽 **문제 카드 16장** (A6, 4영역 × 4장, 2쪽에 8장씩 — 영역별 색 띠: 환경 초록 · 사회적 약자 파랑 · 정서 주황 · 재난 빨강). 카드 문구(각 한 문장, 아래에 "내가 만든 문제:" 빈 카드 2장 포함):
- 환경: ① 분리배출을 헷갈려서 일반 쓰레기통에 재활용품이 들어가요 ② 교실에 아무도 없는데 불이 켜져 있어요 ③ 급식 잔반이 너무 많이 남아요 ④ 비 오는 날 우산을 두고 가서 우산이 쌓여요
- 사회적 약자: ① 시각장애인이 횡단보도 앞에서 신호를 알기 어려워요 ② 땅콩 알레르기가 있는 친구가 급식 반찬을 알아보기 어려워요 ③ 휠체어 친구가 복도 장애물을 피하기 어려워요 ④ 한글을 막 배운 동생이 안내 표지를 이해하기 어려워요
- 정서: ① 쉬는 시간에 혼자 있는 친구가 외로워요 ② 시험 전에 긴장해서 마음이 불안해요 ③ 칭찬을 받으면 좋은데 칭찬할 기회가 적어요 ④ 학교에 오기 싫은 아침이 있어요
- 재난: ① 불이 났을 때 어느 쪽으로 대피할지 헷갈려요 ② 지진이 나면 책상 밑으로 가야 하는데 잊어버려요 ③ 계단에서 사람이 몰려 위험해요 ④ 비상구 앞에 물건이 쌓여 있어요
(실제 학생·교사 이름 쓰지 않음)
9쪽 **2×2 매트릭스 판** (A3 또는 A4 확대) — 가로 해결 가능성 높음/낮음, 세로 중요성 높음/낮음, 칸마다 A·B·C·D 큰 글자. 모둠당 1장 + 포스트잇(문제 붙이기).
10쪽 **그림 카드 — 급식 알레르기 탐지견** (A6 2×2, 8장): 땅콩 그림 2장 · 우유 그림 2장 · 안전한 음식(밥·사과 그림) 2장 · 빈 카드 2장(모둠이 그림). 규칙: 큰 단순 그림 + 글자는 아래 작게, 카드끼리 모양·색이 서로 충분히 달라야 AI가 구분하기 쉬움. 사진·얼굴 금지.
11쪽 **그림 카드 — 내 물건 알아보는 반려견**: 필통·배지 이름표 템플릿(A6 4장): "내 물건(필통) / 친구 물건(필통)" 구분용 큰 스티커 칸. 사람 사진 금지, 물건·배지만.
12쪽 **그림 카드 — 교실 도우미견**: 손 모양 그림 카드(조용히 ✋, 모여 ✊→ 그림으로 표현, 정리 시간 카드) 4장. 실제 손으로 하면 손만 카메라에 보이게, 얼굴이 나오지 않게.
13쪽 **신호등 안내견 보조 카드** — 빨강·노랑·초록 + 그 위에 놓는 "정지/기다려/출발" 글자 카드(5차시 연결 설명용 선택)
14쪽 **로보독 행동 카드** (A6 12장, 설계·코딩 보조, 7차시): 소리 6장(안녕 · 기다려 · 비켜 · 출발 · 멍멍 · 으르렁), 표정 5장(찢눈=화난 눈 · 깜박 · 반짝 눈 · 하트 눈 · 눈 감음), 자세 4장(인사 · 앉기 · 기지개 · 준비), 몸통 불빛 색(빨강·노랑·초록·파랑·주황). 물구나무·점프는 넣지 않음(안전). 카드 뒷면에 블록 이름(편집기에 보이는 한국어)은 교사가 확인 후 적기.
15쪽 **칭찬 쪽지 12장**(A6 가로 3장 × 4): "______ 모둠에게 / 좋았던 점 / 더 좋아질 점 / 쓴 모둠 ____". 사용 예시 문구 하단 박스 1개.
16쪽 **갤러리 워크 종이**(A3 또는 A4 2장 붙이기): 위에 모둠 이름·로보독 이름·주제·문제 정의 한 문장·설계표 1줄 쓰는 칸, 아래 쪽지 붙이는 칸.
17쪽 **한 쪽 안내**(교사 보관): 카드 인쇄 가이드, 라벨 번호표, 8차시 발표 순서표(8모둠 × 시간).
