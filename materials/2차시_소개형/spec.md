# 2차시 소개형 수업 꾸러미 — 제작 명세 (내용 확정본)

대상: 초등 5~6학년, 40분 × 2차시. 모둠 3~4명, 모둠당 로보독 1대.
근거: docs/01_소개형_2차시.md, docs/04_활동지_평가.md, docs/05_교사용_운영가이드.md (2026-11-07 실물 확인 반영).

## 실물에서 확인된 사실 (반드시 반영, 틀리면 수업이 안 됨)
- 로보독 **등에 꽂은 마이크로비트의 A·B 버튼은 가려져서 누를 수 없다.** 로보독 쪽 입력 = **본체 버튼(아래쪽 전원 스위치 옆)**.
- 마이크로비트가 로보독의 **뇌**. 빼면 로보독은 눈만 깜빡이고(대기) 아무것도 안 함.
- 배터리가 약하면 다리가 떨리거나 따로 노는 것처럼 보임 → 수업 전 충전·점검 필수.
- 충전 전용 USB 케이블이면 PC에 MICROBIT 드라이브가 안 보임 → 데이터용 케이블.
- 사이트: 시뮬레이터 https://microbit-bridge.netlify.app/sim/ , AI 브리지 https://microbit-bridge.netlify.app/ai.html
- 예제 파일(사이트 수업 자료 /docs/ 에서 내려받기):
  - `00_check-robodog`: 점검. 켜면 눈 하트, 몸통 불빛 = 배터리(초록 60%↑ / 노랑 30~60% / 빨강 30%↓), 본체 버튼마다 앉기↔서기
  - `00_bridge-receiver`: PC에 꽂는 USB 마이크로비트. 켤 때 B1(모둠번호) 표시. A = 멈춤 잠금, B = 풀기(손에 있으니 누를 수 있음)
  - `01_hello-robodog`: 본체 버튼을 누를 때마다 1 인사(파란 불·"안녕" 소리·인사 자세) → 2 조금 걷기(초록 불, 1초) → 3 앉기(주황 불) → 다시 1
  - `03_ai-traffic-dog`: 라디오 숫자로 행동. 1 빨강 = 멈추고 "비켜!" 소리·빨간 불·찢눈 / 2 노랑 = 멈춰서 기다림·주황 불 / 3 초록 = 천천히 출발(속도 25)·초록 불 / 0·4(배경) = 멈춤·눈 감음. **2초 동안 신호가 없으면 스스로 멈춤.** **본체 버튼 = 멈춤 잠금 ↔ 풀기(잠그면 눈에 X).** 켤 때 R1(모둠번호) 표시.
- 멈추는 방법 3가지: ① AI 브리지 화면 [■ 멈춤] 또는 키보드 Esc ② 로보독 본체 버튼(멈춤 잠금) ③ 로보독 전원 스위치. (+ 자동: 신호 2초 끊기면 멈춤, 브리지 창을 내려도 멈춤)
- 확신 % 는 "맞을 확률"이 아니라 "AI가 자신 있어 하는 정도". 처음 보는 주황 카드를 노랑 100%로 답하는 것이 실제로 확인됨(assets/ai_orange.png).

## A. 수업 슬라이드 (PPT 16:9, 24장, 슬라이드마다 발표자 노트 = 교사 대본)

노트 형식: `[시간] 발문: … / 예상 답: … / 진행: … / 주의: …` (해당 없는 칸은 생략)

### 1차시 — 로보독을 만나요
1. **표지** — "로보독을 만나요" / 부제 "피지컬 AI 교실 1차시" / 이미지 story_hello.png
   노트: [0'] 로보독·마이크로비트 배부 전에 화면만 띄워 둡니다.
2. **오늘의 목표** — ① 피지컬 AI가 무엇인지 말할 수 있어요 ② 로보독의 눈·뇌·몸을 찾을 수 있어요 ③ 버튼으로 로보독을 움직여 봐요
3. **안전 약속 3가지** — 떨어뜨리지 않기(책상 가장자리 금지) · 천천히(속도는 30 이하) · 위험하면 바로 전원 끄기
   노트: [준비 5'] 발문: "로봇이 책상에서 떨어지면 어떻게 될까요?" / 진행: 모둠별 배부, 전원 켜기, 안전 서약서 서명 / 주의: 배터리 확인(몸통 불빛 초록이면 OK — 수업 전 점검 예제)
4. **이 로봇은 어떻게 알고 움직였을까?** — 큰 물음표 + story_walk.png
   노트: [도입 5'] 진행: 교사 로보독으로 본체 버튼 → 인사 시연 / 발문: "누가 로봇에게 인사하라고 알려 줬을까요?" / 예상 답: 버튼, 프로그램, 사람이 시켜서
5. **피지컬 AI = 눈 + 뇌 + 몸** — 세 칸 그림: 눈(센서·카메라: 보고 느끼기) → 뇌(마이크로비트·AI: 판단하기) → 몸(모터·LED·스피커: 움직이기)
   노트: [개념 7'] 발문: "사람은 무엇으로 보고, 무엇으로 생각하고, 무엇으로 움직이나요?" / 진행: 사람과 로봇을 나란히 비교
6. **생활 속 피지컬 AI** — 로봇 청소기(장애물 보고 피함) · 자율주행차(신호등·사람 보고 멈춤) · 배달 로봇(길 보고 이동). 각 카드에 "눈 / 뇌 / 몸" 한 줄씩
   노트: 발문: "우리 주변에서 스스로 보고 움직이는 기계는?" / 예상 답: 로봇 청소기, 키오스크, 자율주행차
7. **로보독 몸 살펴보기** — sim_robodog3d.png + 찾을 부품 목록: 눈 LED(8×8 두 개) · 몸통 LED · 거리센서 · 카메라 · 마이크로비트 자리(등) · 본체 버튼(아래, 전원 스위치 옆) · 전원 스위치
   노트: [관찰 8'] 진행: 관찰지 1번 — 실물에서 찾아 체크 / 주의: 다리를 손으로 억지로 꺾지 않기(모터 고장)
8. **마이크로비트 = 로보독의 뇌** — "등에 꽂으면 프로그램대로 움직여요" / "꽂으면 A·B 버튼은 가려져요 → 본체 버튼을 써요" / "빼면? 눈만 깜빡이고 쉬어요"
   노트: 진행: 마이크로비트를 뺐다 꽂아 보여 주기(전원 끈 상태에서!)
9. **체험: 본체 버튼을 눌러 보세요** — 1번째 인사 → 2번째 조금 걷기 → 3번째 앉기 → 다시 1번째 (그림: 버튼 + 화살표 순환)
   노트: [체험 10'] 진행: 모둠별로 돌아가며 누르기, 관찰지 2번에 순서 기록 / 주의: 걷기 전 앞 30cm 비우기
10. **숫자를 바꾸면?** — sim_page.png + "속도 30 → 15 로 바꾸면 어떻게 될까?" "1초 → 3초로 바꾸면?"
    노트: 진행: 교사 PC 시뮬레이터에서 숫자만 바꿔 실행(학생 코딩 없음) / 예상 답: 느려진다, 더 멀리 간다
11. **정리: 로보독은 아직 '보지' 못해요** — story_card.png + "다음 시간: 로보독에게 눈(AI)을 달아 줘요!"
    노트: [정리 5'] 발문: "오늘 로보독은 스스로 판단했나요?" / 예상 답: 아니요, 버튼을 눌러야 움직였어요 / 진행: 관찰지 3번(출구 질문), 전원 끄기·정리
