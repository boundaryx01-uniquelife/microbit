## 포니봇 사실 (자료에서 확인된 것만)
- **코딩은 포니봇 시뮬레이터에서 한다.** 주소 `https://microbit-bridge.netlify.app/sim/?kit=ponybot`(첫 화면 → 포니봇 → 시뮬레이터). 포니봇 확장(aiPonybot)이 MakeCode 편집기에 미리 들어 있어 학생이 확장을 추가하지 않는다. 블록을 고치면 오른쪽 포니봇(3D, [2D 보기])이 바로 움직이고, 마이크로비트에 넣을 때는 편집기 아래 [다운로드] → MICROBIT 드라이브. **시뮬레이터는 추정 모델이라 실물과 속도·거리가 다를 수 있다 — 실물과의 일치는 확인하지 않았다(실물 미검증).** 같은 컴퓨터의 AI 브리지가 인식한 번호는 시뮬레이터 포니봇에 라디오처럼 전달된다.
- 입력은 마이크로비트 **A·B 버튼**. 예제별 역할은 각 .ts 머리 주석 그대로: 00 = A 바퀴 점검(앞→뒤→오른쪽 옆→왼쪽 옆 각 1초) · B 즉시 정지 / 01 = A 누를 때마다 다음 장면(1 인사로 제자리 살짝 돌기 · 2 앞으로 1초 · 3 옆으로 1초 · 4 멈춤 → 다시 1) · B 멈춤 / 02 = A 출발↔멈춤 · B 멈춤 / 03·04 = B 멈춤 잠금↔풀기(잠그면 X·LOCK). **A·B가 포니봇에 꽂았을 때 가려지는지는 실물 확인 항목.**
- 바퀴는 **메카넘** → 옆·대각선 이동 가능(블록 "메카넘 … 방향 …로 이동", 9방향 ↖↑↗←정지→↙↓↘, 속도 0~255). 일반 이동 블록 "포니봇 … 방향 …로 이동"(↑↓ 회전 2종)도 있으나 ↶ 기호에 Clockwise가 연결돼 있어 회전 방향은 실물 확인 후 표기.
- 표현 수단은 **마이크로비트 LED 아이콘 + 포니봇 OLED 화면(128×64, 영문·숫자만, 블록 "문장 출력"·"숫자 출력"·"디스플레이 지우기")**. 소리·몸통 불빛·표정은 없다. 네오픽셀(별도 확장 ai_ponybot_light)은 1차에서 쓰지 않는다. 라인센서·컬러센서도 있으나 이 꾸러미에서는 쓰지 않는다.
- **거리센서(초음파, 블록 "…단위로 측정한 거리")는 반사가 없으면 0이 아니라 500(최댓값)을 돌려준다.** 예제는 0 또는 500 이상을 "못 읽음 → 멈춤"으로 처리한다. 교사용 안내에서 반드시 강조한다("500 = 아주 멀다"로 읽으면 계속 달린다). 같은 이유로 02·03 예제는 **앞쪽에 센서가 읽을 수 있는 벽·상자가 있어야 출발**한다(없으면 NO SIGNL/BLOCKED로 멈춤).
- 속도(예제 기본 80, 범위 0~255)와 가까움기준(20cm)은 **예시 값이며 교사가 실물로 정할 정책 값**이다. 이 꾸러미는 "안전 속도는 ○○"처럼 숫자를 정해 주지 않는다. 학생용 화면에는 "선생님이 정한 속도"로 쓴다.
- 멈추는 방법: ① AI 브리지 [■ 멈춤] 또는 Esc ② 마이크로비트 B 버튼(멈춤 잠금) ③ 포니봇 전원 스위치. 자동: 신호가 2초 끊기면 멈춤(03·04), 03은 초록이어도 앞이 가깝거나 못 읽으면 멈춤. 04 틀에는 앞 거리 확인이 없으므로 행동은 1초 이내로 짧게 하고 반드시 멈추기.
- 예제 화면 글자(영문·숫자): 02 = WAIT / TOO NEAR / GO / NO SIGNL, 03 = RED STOP / YELLOW WAIT / GREEN GO / BLOCKED / LOCK, 04 = ONE / TWO / THREE / LOCK, 켤 때 GROUP + 모둠번호(마이크로비트 LED에는 R+번호, USB 수신기는 B+번호).
- AI 브리지 주소: `https://microbit-bridge.netlify.app/ai.html?kit=ponybot`. 예제 글자 코드(.ts) 내려받기: `https://microbit-bridge.netlify.app/ponybot/` (04 예제가 목록에 있는지는 build-kit 재실행 후 확인). 공식 스마트폰 앱(블루투스)과 섞어 쓰지 않는다(마이크로비트는 블루투스와 라디오를 동시에 쓸 수 없음).
- 이 수업은 모둠 PC에서 AI 브리지(웹캠) → USB 마이크로비트(00_bridge-receiver, 모둠번호 맞춤) → 라디오 → 포니봇 마이크로비트(03·04). 확신 %는 "맞을 확률"이 아니라 "AI가 자신 있어 하는 정도".
- 마이크로비트는 포니봇용(01·02·04 / 03)과 컴퓨터용(00 수신기)으로 라벨을 붙인다. 먼저 시뮬레이터에서 시험하고, 실물 다운로드·재연결(모둠당 3~5분)은 확인된 코드만 한 번 한다.
