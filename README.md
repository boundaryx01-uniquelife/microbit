# 빅아이 로보독 × 마이크로비트 피지컬 AI 수업 자료 (초등 교사용)

초등학생이 계정 없이 **직접 AI를 학습시키고**, 그 결과로 **로보독(로봇)을 움직이는**
피지컬 AI 수업 자료입니다.

## 왜 'AI 브리지'가 필요한가

빅아이 로보독 마이크로비트 확장(`kocoafab/robodog`)에는 AI 카메라 블록이 없습니다.
그래서 웹캠 + 브라우저 AI로 인식하고, 결과를 마이크로비트 라디오로 로보독에 보냅니다.

```
웹캠 → AI 브리지(크롬) → USB → 다리 마이크로비트 → 라디오 → 로보독 마이크로비트 → 로보독
```

## 빠른 시작 (교사)

1. **다리 마이크로비트**: MakeCode 새 프로젝트 → `makecode/00_bridge-receiver.ts` 붙여넣기 → 다운로드.
   ⚠ 이 프로젝트에는 로보독 확장을 넣지 마세요.
2. **로보독 마이크로비트**: 새 프로젝트 → 확장에서 `kocoafab/robodog` 추가(전체 입력)
   → `makecode/03_ai-traffic-dog.ts` 붙여넣기 → 다운로드 → 로보독 등에 꽂고 전원 ON.
3. 두 코드의 `모둠번호`를 같게 맞추세요(모둠마다 다르게).
4. `bridge/index.html`을 크롬으로 열기 → 카메라 켜기 → 카드 학습 → 마이크로비트 연결(USB).

## 검증 상태

- MakeCode 예제 5개: pxt-microbit 9.1.2 컴파일 성공
- AI 브리지: 헤드리스 크롬 + 가짜 웹캠으로 모델 로딩·학습·인식 동작 확인
- **실물 로보독 연동은 미검증** — 수업 전 교사 실기 점검 필요 (`docs/00` 6절 참고)
