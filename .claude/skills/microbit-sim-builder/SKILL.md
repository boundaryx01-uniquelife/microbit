# 마이크로비트 시뮬레이터·블록·코드 생성

기준 구현: `boundaryx01-uniquelife/microbit`의 `bridge/sim/`(로보독). 새 교구는 **틀(실행기·월드·뷰·도우미 UI)은 그대로, 교구 어댑터만 새로** 만든다.

> **화면도 같은 틀이다.** 새 교구용 페이지를 따로 만들지 않는다 — 같은 시뮬레이터 앱에 교구 어댑터(`bridge/sim/kits/<slug>.js`)를 끼우고 `/sim/?kit=<slug>`로 연다. 같은 화면 배치, **MakeCode 블록 코딩 탭**(확장 커밋 고정), 글자 코드 탭, 예제·도우미·장면 편집이 교구와 무관하게 똑같아야 한다. (포니봇 첫 시험에서 하위 에이전트가 새 페이지를 만들어 화면이 달라지고 블록 탭이 빠졌다 — 사용자가 바로 지적.)
> **실행하면 무엇을 눌러야 하는지 보여 준다.** 예제가 A 버튼·라디오를 기다리면 실행 직후 그 버튼을 강조하고 안내한다(아니면 '안 움직인다'로 보인다).

세 시스템은 **블록 표 하나**(`kit.blocks.json`)를 함께 쓴다 — 시뮬레이터 API, 예제, 규칙 도우미 어휘, AI 프롬프트, 출력 검사가 모두 여기서 나온다. 표가 틀리면 셋이 같이 틀리므로 표부터 만든다.

```
확장 소스(GitHub) ──extract-blocks.py──▶ kit.blocks.json ─┬─▶ ① 시뮬레이터 API 어댑터(+운동학·센서)
                                                          ├─▶ ② 예제 .ts → MakeCode 블록 변환 시험
                                                          └─▶ ③ 규칙 도우미·AI 프롬프트 ─▶ validate-code.mjs
```

## 진행 순서

### 0. 블록 표 받기 (모든 것의 원천)
```bash
python3 -I scripts/extract-blocks.py <owner>/<repo>#<commit> --out kits/<slug>/blocks.json --md kits/<slug>/blocks.md
```
- 커밋을 붙여 고정한다(편집기의 확장 고정 해시와 같은 커밋). `pxt.json`의 `files` → `.ts`의 `//% block=… blockId … min/max/defl`, enum 멤버, `_locales/ko` 번역을 읽는다. 기억으로 쓰지 않는다.
- 결과 표를 사용자에게 보여 주고 **보조 확장**(조명·네오픽셀 등 별도 저장소)도 있는지 묻는다.
- 블록 이름만 보지 말고 **구현을 읽는다**: 모터 번호와 바퀴 위치, 값 자르기(예: `speed*16`을 4095에서 자름), 센서 '못 읽음' 값(0인지 최대값인지). 시뮬레이터 정확도는 이 읽기에서 나온다.
- 구현에서 읽은 사실은 표 옆 `kits/<slug>/facts.json`에 적는다(추출기는 못 채움): 모터→바퀴 위치, 값 자르기, 센서 못 읽음 값(예: 포니봇 `ping` 반사 없음 = 500), 근거 줄. 시뮬레이터·도우미·문서가 이 파일을 함께 본다.
- 한글 낱말은 `kits/<slug>/vocab.json`(enum 멤버·함수별 동의어: "앞/앞으로/직진" → `Mecanum.Forward`)에 따로 둔다. 확장의 블록 글자는 화살표(↑ ↶)뿐인 경우가 많아 표만으로는 말을 못 알아듣는다. vocab의 모든 대상이 표에 실제로 있는지 시험한다.

### ① 시뮬레이터 — `references/simulator.md`
1. 수준 결정: 0 없음 / 1 2D 위에서 보기 / 2 3D (작업량 표를 보여 주고 사용자가 고름).
2. 재사용: `compile()`(Babel로 TS 제거 + 모든 호출 `await` + 반복문 맨 위 `__yield`), `Runner`(협동 실행, `forever`·핸들러·정지 세대), `World`(공간·장애물·추락·raycast). 확장에 **콜백을 받는 블록**이 있으면 `addAsyncNs('<ns>')`로 등록(그 콜백 안의 호출이 기다리게). `Runner`는 서브클래스로 `buildEnv`에 교구 네임스페이스·enum을 더한다(`references/simulator.md` 7절).
3. 교구 어댑터: `make<Kit>Api(R, h)` 팩토리(블록 표의 함수마다 하나), `Robot.reset/step(dt)` 운동학(템플릿: 4족·차동·메카넘 — 6절), 센서(raycast 거리, 바닥 캔버스 라인, 색 패치), 표시 장치(OLED·LED)를 패널로.
4. **환경도 시뮬레이션한다**(사용자 요구): 코드가 쓰는 센서를 보고 실행할 때 필요한 물체를 **없을 때만** 자동으로 놓는다(거리 → 상자, 색 → 색 물체·컬러칩, 라인 → 검은 선). 사용자가 옮긴 배치는 지우지 않는다. 모든 물체는 화면에서 끌기·추가·지우기(실행 중에도), 센서 값이 바로 따라 바뀌게. 공용 모듈 `bridge/sim/props.js`(소품·센서 계산·편집기), `maps.js`·`mapui.js`(레벨별 지도 + 30cm 타일 편집기 + 저장·내보내기, 대회 규칙 수치로 재구성한 연습장은 '공식 맵 아님' 표시)를 다시 쓴다. 카메라처럼 실물 값 대응표가 펌웨어에 있는 것(색 → 클래스 번호)은 화면에서 바꿀 수 있는 설정 + '실물 확인 필요'.
5. 추정 상수는 `EST` 한 곳에(최대 속도 cm/s, 회전 °/s, 치수) — 실측하면 바꾸고 "추정"표시를 지운다.
6. 시험(Playwright, 오프라인/인터넷 필요를 나눔, `fastForward` 훅, 장면 자동 준비·끌기 후 센서 값 변화 포함): 앞 1초 이동 거리, 제자리 90° 회전, 옆 이동 시 heading 불변(메카넘), 장애물 앞 거리, 추락, `while(true){}`에도 응답, 미지원 블록 경고, 예제 전부 오류 0, 390px 가로 스크롤 없음. `window.__sim`으로 상태를 읽는다.

### ② MakeCode 블록 — `references/makecode-blocks.md`
1. 편집기 삽입: `makecode.microbit.org/?controller=1` iframe + postMessage(origin 검사), 확장은 **커밋 해시로 고정**해 미리 넣는다(`github:owner/repo#sha`) — 확장이 바뀌어도 수업이 깨지지 않게. 60초 안에 응답 없으면 JS 탭으로 폴백.
2. 예제 `.ts` → `tests/build-sim-examples.js`로 시뮬레이터 예제 목록 생성, `tests/makecode-blocks.js`로 실제 MakeCode에서 **블록 변환** 확인(확장 추가 → 붙여넣기 → 블록 탭에 오류 없음).
3. 예제·생성 코드 모두 `scripts/validate-code.mjs`로 표 검사(아래).

### ③ 코드 생성 도우미 — `references/codegen.md`
두 모드, 같은 UI, 같은 검사:
- **오프라인 규칙 워크플로(기본, 키·인터넷 불필요)**: 입력 검사(길이·개인정보 안내) → 트리거로 문장 나누기(“A 버튼을 누르면”, “라디오 3을 받으면”, “가까우면”, “계속”) → 조각별 동작 사전(블록 표의 한글 블록명·동의어에서 만든 표) → 코드 템플릿 조립 → 경고·추천 예제. 못 알아들은 조각은 경고로 돌려준다(추측해서 넣지 않음).
- **Claude API 모드(선택)**: 서버 함수(Netlify 등)에서만 키 사용, 수업 코드가 맞을 때만 켜짐, 실패·미설정이면 규칙 모드로 자동 폴백. 프롬프트의 블록 문법 부분은 **블록 표에서 생성**(손으로 베끼지 않음), 구조화 출력(json_schema: code·explanation·warnings). 모델은 설정값(기본은 기준 구현 값 유지).
- **출력 검사(두 모드 공통)**: `validate-code.mjs` — 표에 없는 함수/enum(환각), 네임스페이스 빠진 enum(`Mecanum.Forward` → `aiPonybot.Mecanum.Forward`), 확장 범위 밖 숫자, 인자 수, 문법 → 오류면 코드 대신 설명과 함께 돌려줌. 서버에서도 돌린다(브라우저 검사는 우회 가능).
- **규칙 도우미에 필요한 정책 키**(`kits/<slug>/policy.json`): `defaultSpeed`·`defaultSeconds`(문장에 숫자가 없을 때만), `nearCm`, `radioTimeoutMs`, `maxSpeed`·`autoStopMs`(null = 한도 없음), `forbid`, `maxChars`, 교구 설정(예: 컬러센서 버전). 값마다 `_note`로 자리표시자인지 표시. **null이면 숫자를 지어내지 않고 되묻는다.** 검사기에는 `policy.max["ns.fn.param"]` 모양으로 바꿔 넘기고, 도우미 출력은 `strictPolicy:true`(정책 위반 = 거절).
- **문장 나누기 함정**: 마침표로 나누면 "1.5초"가 깨진다 — 숫자 사이 `.`은 예외.
- **검사기 배포**: `scripts/validate-code.mjs`를 사이트 안(예: `bridge/sim/validate-code.mjs`)으로 복사해 브라우저·서버 함수가 import. 원본은 스킬, 복사 뒤 `diff`로 같게 유지. 표에는 확장 블록만 있어 `basic`·`input`·`radio`는 검사 범위 밖.
- **정책 값은 사용자(교사)가 정한다**: 속도 한도·자동 멈춤 시간 등은 `policy.json`(또는 환경 변수) 설정값. 스킬이 숫자를 정하거나 바꾸지 않는다. 기존 교구 값이 있으면 그대로 기본값으로 두고, 새 교구는 비워 두고 사용자에게 묻는다. 시뮬레이터는 정책과 무관하게 확장의 실제 범위를 재현한다.

## 지켜야 할 원칙
- **소스가 근거**: 블록 이름·주석이 아니라 구현 코드로 동작을 정한다. 소스로 확정 못 한 것(바퀴 배치·센서 극성·실제 속도)은 "확인 필요"로 kit 설정과 문서에 남긴다.
- **시뮬레이터는 추정 모델**: 화면에 "추정" 표시, 실물 미검증 항목을 목록으로 사용자에게.
- **개인정보**: 규칙 모드는 글이 브라우저 밖으로 안 나간다고 표시. AI 모드는 무엇이(문장·현재 코드) 어디로 가는지 표시, 이름·학교 쓰지 말라는 안내, 코드 전송은 기본 끔.
- **제조사 자료**: 공식 이미지·문서는 허락 범위와 출처를 `SOURCE.md`(파일별 원본 주소·라이선스)로 남긴다.
- **하위 에이전트를 만들 때마다 사용자에게 알린다**: 맡은 일·모델·사고 깊이·이유. 분량이 작아 직접 했으면 "위임 없음"이라고만 적는다. 블록 표 추출·시험 실행은 Haiku/Sonnet, 운동학 부호·안전 설계·최종 검토는 메인.
