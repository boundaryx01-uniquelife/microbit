# 시뮬레이터 수준 고르기

| 수준 | 무엇 | 학생 경험 | 작업량(대략) | 고를 때 |
|---|---|---|---|---|
| 0 | 자체 시뮬레이터 없음. MakeCode 기본 마이크로비트 시뮬레이터 + 동작 설명 그림 | 코드는 짜지만 교구 움직임은 실물에서만 | 작음 | 실물이 모둠마다 있음, 일정이 급함 |
| 1 | 2D 위에서 보기: 몸 위치·방향·궤적, LED/얼굴, 센서(거리) 표시 | 집·실물 없는 반에서도 "움직임" 확인 | 중간 | 바퀴형(차동 구동)처럼 2D로 의미가 충분한 교구 |
| 2 | 3D: 관절·자세·표정까지 | 다리형·팔형처럼 자세가 수업 내용일 때 | 큼(운동학 실측표 + 메시 + 카메라) | 자세·동작 자체가 학습 목표, 실측 자료 확보 |

## 수준 1 이상일 때 필요한 것
- 블록 표(api) → 시뮬레이터 API 어댑터: 각 블록이 Robot 상태를 어떻게 바꾸는지(속도→cm/s, 회전→°/s 추정 상수, 시간).
- 장치 감지: 코드에 쓰인 센서·버튼·카메라 블록을 찾아 화면에 장치 카드 표시.
- 비동기 처리: 블록 호출에 `await`를 넣는 변환 대상 네임스페이스 등록.
- 시험: 걷기/주행 거리·회전 각 수치, 무한 반복 경고, 추락(책상 끝), 장애물.

## 3D(수준 2) 추가
- 관절 운동학: 실측 표본(높이·발끝 → 관절 각) 또는 공식 자료. 없으면 "추정"으로 명시.
- 메시: 실물 사진의 실루엣 비율(머리 형태·LED 위치)을 맞춘다 — 마스코트·로고와 같은 특징 표를 쓴다.
- 성능: 저사양 PC를 위해 자동 화질 낮춤, 첫 화면에는 3D를 쓰지 않는다(미리 렌더 영상).
