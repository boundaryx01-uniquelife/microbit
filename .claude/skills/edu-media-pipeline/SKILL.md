# 교육 미디어 파이프라인

교육용 사이트(수업 자료·시뮬레이터·첫 화면)에 들어가는 **보이는 것 전부**를 같은 브랜드로 묶어 만든다. 한 번에 전부 할 필요는 없다 — 요청에 맞는 모듈만 골라 그 참고 문서만 읽는다.

## 모듈 고르기

| 요청 | 모듈 | 읽을 문서 |
|---|---|---|
| 색·로고·파비콘·공유 이미지, "로고가 이상해" | ① 브랜드 키트 | `references/01-brand-kit.md` |
| 인트로/엔딩 영상, 모션 그래픽, 첫 화면 영상 | ② 모션 → 영상 | `references/02-motion-to-video.md` |
| 슬라이드·문서 아이콘, 일러스트 통일 | ③ 아이콘 세트 | `references/03-icon-set.md` |
| 카드 높이·글자 크기 들쭉날쭉, PPT 글 넘침 | ④ 슬라이드 일관성 | `references/04-slides-consistency.md` |
| "디자인팀 꾸려서", 고도화, 리뷰 | ⑤ 디자인 리뷰 팀 | `references/05-design-review-team.md` |
| 완성도 점검, 배포, "다 적용됐니?" | ⑥ 점검·배포 | `references/06-qa-deploy.md` |
| 무엇을 하든 시작 전에 | 함정 모음 | `references/pitfalls.md` (짧음, 먼저 훑기) |

여러 모듈이 이어질 때 순서: ① → ② → ③ → ④ → ⑤(각 산출물마다) → ⑥. 앞 단계 산출물(색 토큰, 마스코트 얼굴)을 뒤 단계가 그대로 쓴다 — 그래서 묶어 두는 것이다.

## 공통 원칙 (왜 중요한가)

- **먼저 본다, 그다음 만든다.** 기존 영상·사이트·실물 사진을 캡처해 보고 시작한다. 이번 작업의 가장 큰 실수는 실물 제품(귀 없는 알약형 머리)을 안 보고 마스코트를 그려 "고양이도 원숭이도 아닌" 결과가 나온 것이었다. `scripts/video-frames.sh`, `scripts/shoot-pages.js`로 빠르게 본다.
- **브랜드 충실도 > 장식.** 실제 제품·캐릭터의 형태(실루엣, 눈 표현)를 지키는 게 화려함보다 먼저다. 이어지는 장면이면 앞 영상의 화풍(붓결·팔레트)을 이어받는다.
- **결정적으로 만든다.** 모션은 `render(t)` 한 함수로(시간 t만으로 화면이 정해짐), 아이콘·도식은 생성기 파일로. 그래야 프레임 단위 렌더, 다시 만들기, 시험이 된다.
- **눈으로 검증한다.** 만들 때마다 프레임/아이콘을 contact sheet로 모아 직접 본다(`scripts/contact-sheet.py`). 숫자 테스트가 통과해도 그림이 이상할 수 있다.
- **역할 분담.** 생성형 이미지(Canva 등)는 사물·캐릭터에, 코드는 글자·숫자·정확한 도식에. 생성형 이미지에 한글·숫자를 맡기면 깨진다.
- **정직하게 보고한다.** 실기기 재생·실물 동작처럼 확인 못 한 것은 "확인 못 함"으로 남긴다. 테스트 병렬 실행 실패는 직렬로 재확인 후 판단.
- **토큰 효율.** 넓은 탐색·반복 렌더·리뷰는 하위 에이전트(Sonnet)에, 설계·종합·최종 판단은 메인에서. 같은 파일 수정은 메인 한 곳에서.
- **하위 에이전트를 만들 때마다 사용자에게 알린다:** 맡은 일 · 모델(Haiku/Sonnet/Opus) · 사고 깊이(지정 안 했으면 "기본값") · 그렇게 고른 이유를 한 줄 표로. 사용자가 비용과 품질을 판단할 수 있게.

## 스크립트 (`scripts/`)

| 스크립트 | 용도 |
|---|---|
| `rangeserve.js <dir> <port>` | Range 지원 정적 서버(영상 탐색·테스트용. `python -m http.server`는 Range 없음) |
| `render-frames.js` | 결정적 웹 애니메이션 → PNG 프레임(WebGL 캔버스도 같은 작업 안에서 읽음) |
| `frames-to-mp4.sh` | 프레임 → mp4(H.264, faststart) |
| `video-frames.sh` | 영상 → 요약 contact sheet + 마지막 프레임(이어 붙일 장면 분석) |
| `prep-transparent-icons.py` | 흰 바탕 PNG → 투명·자르기·축소(Canva 내보내기 후처리) |
| `contact-sheet.py` | 이미지 여러 장을 한 장으로(검토용) |
| `shoot-pages.js` | 여러 주소 × 화면 크기 스크린샷 + 콘솔 오류 요약 |

`assets/`에는 이번에 실제로 쓴 예시가 있다: `ending-example.js`(보름달·별→LED 눈 엔딩, 카드 모드 포함), `diagram-icons-example.html`(도식 아이콘 생성기). 새 프로젝트에서는 구조만 참고하고 브랜드 값은 바꾼다.

## 끝낼 때 보고 형식

1. 무엇을 만들었고 어디에 있는지(파일·주소)
2. 확인한 것(테스트 수치, 본 화면)과 **확인 못 한 것**
3. 사용자 결정이 필요한 것(예: 영상 생성 모델 쓸지, 지울 파일)
