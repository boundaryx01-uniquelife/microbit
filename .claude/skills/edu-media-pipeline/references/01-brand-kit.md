# ① 브랜드 키트

목표: 사이트·영상·아이콘·PPT가 같은 집안으로 보이게 하는 최소 묶음 — **색 토큰, 마스코트 얼굴(로고), 파비콘, 공유 미리보기 이미지**.

## 1. 재료 모으기
- 실물 제품 사진·3D 모델 캡처·기존 영상 마지막 장면을 모은다(`scripts/video-frames.sh`, `scripts/shoot-pages.js`).
- 마스코트 특징을 표로 적는다: 머리 형태, 눈 표현(LED 도트·화면), 귀·안테나 유무, 몸 색. **이 표에 없는 특징은 그리지 않는다**(상상으로 귀를 붙였다가 "고양이도 원숭이도 아님" 평을 받았다).
- 영상 프레임에서 팔레트를 뽑는다(PIL `quantize(8)` 후 빈도순). 하늘·밤·피부 같은 큰 면 색과 강조색 1~2개.

## 2. 색 토큰
- 기존 디자인 시스템(예: `brand.css`의 `--accent` 등)이 있으면 **새로 만들지 말고 맞춘다**. 새 색은 "밤 남색 / 달빛 크림 / LED 크림" 같이 이야기와 연결된 2~3개만 추가.
- 아이콘 배경 파스텔은 생성형 아이콘(Canva)에서 실제로 나온 색을 측정해 코드 도식에도 같은 값을 쓴다.

## 3. 로고(마스코트 얼굴) SVG
- 32×32 viewBox, 단색 면만(그라디언트·필터 없이 — 한 페이지에 여러 번 인라인돼도 id 충돌 없음).
- 구성 예(로보독): 남색 둥근 사각 배경 → 크림 보름달 원 → 검은 알약형 머리 → 어두운 눈 판 2개 → 크림 LED 점으로 ^^ 꺾쇠(점은 좌우 대칭으로 직접 찍기 — `stroke-dasharray` 점선은 꼭짓점에서 점이 겹쳐 고르지 않음).
- 16·32·44·64·256px와 어두운 배경에서 미리 보기(contact sheet)로 확인.
- 교체 범위: `favicon.svg`, `logo.svg`, 각 페이지 머리 메뉴의 인라인 SVG, **문서 생성기 틀**(예: `tools/build-docs.mjs`) — 생성기를 안 바꾸면 다음 빌드 때 옛 로고가 돌아온다. 정규식으로 `<svg aria-hidden="true" viewBox="0 0 32 32">…</svg>`를 일괄 교체하고 개수를 세어 확인.

## 4. 공유 미리보기(og:image)
- 1200×630 PNG. 엔딩 마지막 장면(제목 포함)을 그대로 캡처하면 영상과 일관됨.
- 큰 PNG면 `quantize(256)`로 줄인다(약 1MB → 0.5MB).
- 메타: `og:title/description/image(+width/height/alt)`, `twitter:card=summary_large_image`, `theme-color`.
- `.gitignore`가 `*.png`를 막는지 확인하고 예외 추가 → 운영 주소에서 200 확인.
