# 함정 모음 (실제로 시간을 잃었던 것들)

| 증상 | 원인 | 해결 |
|---|---|---|
| 영상 `currentTime`을 바꿔도 0초에 머무름, 프레임 렌더에 엉뚱한 배경 | 로컬 서버가 HTTP Range를 지원하지 않음(`python3 -m http.server`) | `scripts/rangeserve.js` 또는 배포 주소(Netlify 등은 Range 지원)에서 렌더·시험 |
| WebGL 캔버스 `toDataURL()`/`drawImage`가 빈 화면 | `preserveDrawingBuffer:false`라 다음 작업 전에 버퍼가 지워짐 | seek(그리기)과 읽기를 **같은 `page.evaluate` 안에서**. 엔진의 "끝" 콜백이 마지막 그리기 직후 동기로 불리면 거기서 스냅숏 |
| 헤드리스 3D 렌더가 실시간보다 2~3배 느림 | 소프트웨어 렌더(swiftshader) | 실시간 재생 캡처 말고 프레임 단위 seek 렌더. 30fps·30초 ≈ 900장 ≈ 25~40분 — 백그라운드로 |
| Canva `generate-image` 결과가 200px | 받는 건 미리보기 | 빈 디자인에 페이지를 추가해 `insert_fill`로 넣고 `export-design`(png, 1024px)로 받기. `create-design`은 빈 화면 대신 예시 디자인을 만들므로 새 페이지를 쓴다 |
| Canva 결과 그림체가 제각각 | 매번 독립 생성 | 먼저 만든 1~2장을 `imageReferences`로 넣고 프롬프트에 같은 스타일 문구 고정 |
| Canva `remove-background`가 배경 원까지 남김 | 원을 피사체로 봄 | 원은 디자인 요소로 두고, 바깥 흰색만 `prep-transparent-icons.py`로 투명화 |
| 아이콘이 슬라이드에서 작아 보임 | PNG에 투명 여백이 큼 | 내보낼 때 그림 크기로 자르기(bbox + 작은 여백) |
| 도식 아이콘 글자가 교실 화면에서 안 보임 | 아이콘 안 글자 30px, 화면에서 1/3로 축소 | 아이콘 내부 글자 40px 이상(원본 800px 기준), 그림은 배경 원 안에 |
| 같은 줄 카드의 본문 시작선이 다름 | 제목 줄 수가 달라 머리 높이가 다름 | 웹: CSS subgrid / PPT: 머리 높이·글자 크기를 줄 단위 최댓값·최솟값으로 통일 |
| 병합했는데 운영 사이트가 안 바뀜 | 대부분 **빌드 대기·진행 중**(Netlify는 몇 분~수십 분 늦을 수 있음 — 실제로 47분 지연된 적 있음). 자동 배포 꺼짐은 드묾 | 바로 직접 배포하지 않는다. 사용자에게 배포 목록(Deploys/Activity) 캡처를 받거나, 운영 주소를 몇 분 간격으로 확인하며 기다린다. 목록에 그 커밋 빌드가 없거나 실패일 때만 원인을 찾고 `deploy-site`로 직접 배포 |
| 테스트 10개 병렬 실행 시 몇 개 실패 | CPU 부하로 시간 민감 항목 실패 | 직렬로 다시 돌려 재현되는지 확인 후 판단 |
| PR 병합 시 충돌(이미 병합된 내용인데) | squash 병합 후 같은 브랜치에 계속 커밋 | 기본 브랜치를 `-X ours`로 합치기 전에 `git diff`로 내용 동일 확인. 강제 푸시는 쓰지 않음 |
| `*.png` 무시 규칙 때문에 og.png가 한 번도 안 올라감 | .gitignore | 공유 이미지 등 필요한 파일은 예외 규칙 추가, 운영 주소에서 200 확인 |
| 휴대폰 세로에서 가로 영상이 작은 띠 | contain 맞춤 | 같은 영상을 흐리게 키워 배경으로(세로에서만 받기) + 자막 키우기. 근본 해결은 9:16 별도 렌더 |
| 기존 마스코트를 상상으로 그림 → 다른 동물처럼 보임 | 실물 확인 안 함 | 실물 사진·3D 모델 캡처부터. 특징(머리 형태·눈 표현·귀 유무)을 표로 적고 시작 |
