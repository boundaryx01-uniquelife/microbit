판단: 초음파 쪽을 앞으로 보면 M1 = 오른쪽 앞(FR), M4 = 왼쪽 앞(FL). 확장 소스의 대각선 쌍(↖: M1+M3, ↗: M2+M4)과 합치면 M3 = 왼쪽 뒤(RL), M2 = 오른쪽 뒤(RR).
→ `runNormal(Clockwise)`(M1·M2 전진 = 오른쪽 바퀴 전진)은 위에서 보면 **반시계** 회전. 블록 글자 화살표 ↶ 와 일치(코드 이름만 반대).
확인됨: 앞 = 초음파 쪽 — 실물 확인(2026-11-11, 사용자).
남은 확인: 회전 방향(`runNormal(Clockwise)` = 반시계 ↶)은 사진(기판 글자)·블록 화살표 근거 — 실물 회전 방향 확인 권장(바퀴 옆 B/F 표시등과 함께 3초 시험).
