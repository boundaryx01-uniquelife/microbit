중학교 (정보, 45분)

연계 영역: 인공지능(학습 원리·분류·사회적 영향), 컴퓨팅 시스템(피지컬 컴퓨팅), 알고리즘과 프로그래밍

차시 초등과 다른 점 활동
1 블록 대신 MakeCode JavaScript/Python 텍스트 코딩 01_hello-robodog을 JS로 읽고 함수로 나누기
2 규칙 설계를 상태 기계로 02_distance-rule의 지금상태(0~3)를 상태도로 그리고, 회피 상태 추가
3 통신 규약 설계 번호 의미표 작성, 끊김 감시(2초)·하트비트(0.6초)가 왜 필요한지 실험: USB를 뽑고 로보독 반응 관찰
4 변인 통제 실험 심화 패널에서 종류당 사진 5/10/20/40장 × 같은 시험 사진 → 정확도 그래프 (아래 실험 1)
5 오류 비용 토의 신호등에서 "빨강을 초록으로"(위험)와 "초록을 빨강으로"(불편) 중 무엇이 더 나쁜가 → 확신 기준 정하기
6 프로젝트 04_ai-team-template + 상태·통신 설계서

너무 쉬운 부분 대체: 완성 코드 다운로드 → 빈 프로젝트에서 직접 작성, 활동지 A 1~2번 → 실험 1·2 보고서.

고등학교 (인공지능 기초·정보, 50분)

주제 활동 도구
특징 벡터 MobileNet이 만든 1,280차원 특징을 저장(.json)해 파이썬으로 열고 PCA 2D 시각화 브리지 '학습 데이터 저장' + Python(numpy, scikit-learn)
KNN 이해 k를 1~15로 바꿔 정확도 변화, 동점·불균형 데이터의 영향 심화 패널 k 슬라이더
평가 학습/시험 분리, 혼동행렬·재현율, 데이터 누출(연속 프레임을 학습·시험에 섞기) 실험 심화 패널 정확도 실험 + CSV
로봇 내장 AI와 비교 파이썬 kocoafab-robodog 라이브러리로 로보독 자체 AI 카메라(색상·QR·얼굴 추적) 결과를 읽어 웹캠 KNN과 비교 Thonny + kocoafab-robodog(0.2.0), USB 동글·C타입 케이블
안전 설계 페일세이프·워치독·지연 시간 측정(카드 제시 → 로보독 반응까지 시간) 스톱워치/영상
윤리 얼굴인식의 위험, 데이터 치우침, 책임 소재 토론

실험 1 — 데이터 양과 정확도 (중·고 공통)

  1. 심화 패널에서 k 자동을 끄고 k=5로 고정한다(k가 바뀌면 변인 통제가 깨짐). 4종류의 시험 사진을 위치·조명을 바꿔 각 10장 모은다(학습 사진과 다른 장소).
  2. 학습 사진을 종류당 5장 → [정확도 계산] → 기록. '모두 지우기' 후 10, 20, 40장으로 반복. (같은 조건 반복을 위해 '학습 데이터 저장'을 활용)
  3. 그래프: 가로 = 종류당 사진 수, 세로 = 정확도. 혼동행렬에서 자주 헷갈리는 쌍을 찾는다.
  4. 토의: 사진 수보다 다양성이 중요한 경우가 있는가?

실험 2 — 데이터 누출 (고)

  1. 학습 사진을 찍은 직후 같은 자세로 시험 사진을 모아 정확도를 잰다.
  2. 시험 사진을 다른 장소·조명에서 다시 모아 정확도를 잰다.
  3. 두 결과의 차이를 설명한다(연속 프레임은 거의 같은 사진이라 정확도가 부풀려짐).

장비·운영 차이

  • 중·고는 개인 PC 1대 + 모둠 로보독 1대 구성이 현실적입니다. 브리지·USB 마이크로비트는 PC마다, 로보독은 모둠번호로 공유.
  • 파이썬 로보독 제어는 USB 동글(PC↔로봇 무선)을 씁니다. 동글과 마이크로비트 라디오 방식은 별개입니다.
