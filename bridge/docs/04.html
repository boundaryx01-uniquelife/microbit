소개형(2차시)

문항 ◎ 잘함 ○ 보통 △ 노력 필요
학습 데이터를 모았다 4종류를 고르게 20장 이상, 각도·위치를 바꿔 모음 4종류를 모았으나 수·다양성이 부족 도움을 받아 일부만 모음
AI가 틀리는 이유를 말했다 예시(데이터)와 다른 입력이면 자신 있게도 틀린다고 설명 "헷갈려서" 수준으로 말함 이유를 말하지 못함
안전 규칙을 지켰다 멈춤 장치를 스스로 사용, 속도·위치 규칙 준수 안내 후 지킴 반복 안내 필요

기본형(4차시)·전체형 공통

문항 ◎ 잘함 ○ 보통 △ 노력 필요
규칙 vs AI 차이 설명 두 방식 모두 사람의 선택(기준값/예시·이름표)이 들어감을 포함해 설명 한쪽 특징만 설명 차이를 말하지 못함
조건문·라디오로 제어 모든 번호에 행동을 정하고 멈춤 장치를 유지 대부분 동작 예제를 그대로 사용
데이터 개선 실험 결과를 보고 데이터를 바꿔 다시 확인 실험만 함 실험 기록 미흡
윤리·안전 얼굴 미촬영, 오류 시 멈춤·사람 확인을 설계에 반영 안내받아 반영 고려하지 않음

모둠 프로젝트 루브릭(전체형 8차시)

기준 3점 2점 1점
문제 해결 문제 정의(누가·언제·무엇이 불편)를 말하고, 로보독의 각 행동이 그 문제의 어느 부분을 돕는지 1:1로 설명함 행동 일부만 문제와 연결해 설명함 문제와 행동을 따로 설명함(연결 설명 없음)
AI 활용 3종류 이상 + 배경을 학습시키고, 실험 후 사진을 다시 모아 나아진 사례를 1개 이상 보여 줌 3종류 이상 학습했으나 개선 사례 없음 2종류 이하이거나, 같은 카드에 번호가 계속 바뀜
코딩 모든 번호에 행동이 있고 안전장치 3가지(2초 감시·A 잠금·속도 30 이하)가 그대로 동작 한두 번호의 행동이 비었거나 안전장치 1개 빠짐 안전장치를 지웠거나 동작하지 않는 번호가 많음
윤리·안전 AI가 틀릴 때 생길 일과 대처(멈춤·사람 확인)를 구체적 상황 1개 이상으로 설명하고, 얼굴 대신 카드를 쓴 이유를 말함 대처 방법만 일반적으로 말함 대처를 설명하지 못함

성취 수준 환산(4기준 합계 12점): 상 10~12점 · 중 7~9점 · 하 4~6점. 학교 평가 계획의 수준 이름에 맞춰 바꿔 쓰세요.
