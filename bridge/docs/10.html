블록 한눈표 — 하고 싶은 일로 블록 찾기

  1. 하고 싶은 일을 한 문장으로 적어요. (예: "벽이 가까우면 뒤로 물러나요")
  2. 아래 표에서 그 일을 찾고, 가장 비슷한 예제 파일(makecode/…)에서 출발해 숫자나 블록을 조금씩 고쳐요.
  3. 고친 코드는 시뮬레이터(https://microbit-bridge.netlify.app/sim/)에서 먼저 시험하고, 실물은 낮은 속도로 한 번 더 확인해요.

글자 코드(JavaScript)는 블록을 글자로 쓴 것이에요. MakeCode 위쪽의 {} JavaScript 탭에 붙여넣으면 블록으로 바뀌어요. 이 표의 "숫자 뜻·범위"는 시뮬레이터가 받아들이는 값 기준이에요. 시뮬레이터 칸의 뜻: ○ = 움직임을 보여 줘요 / △ = 비슷하게만 보여 줘요 / ✕ = 흉내 내지 못해요.

1. 움직이기 (걷기 · 멈추기 · 돌기 · 앉기)

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
앞으로 걷기 (로보독) 이동 robodog.move(deflib.MoveDirection.Forward, 25) 속도 -100~100. 책상 위에서는 30 이하로 해요 (넘으면 안내가 떠요) ○ makecode/21_remote-dog.ts
뒤로 걷기 (로보독) 이동 robodog.move(deflib.MoveDirection.Backward, 20) 방향만 Backward로 바꿔요 ○ makecode/12_button-explore.ts(앞으로만) → 아래 조합 ①
멈추기 (로보독) 정지 robodog.stop() 걷기를 멈춰요 ○ makecode/02_distance-rule.ts
오른쪽으로 돌기 (로보독) 회전 robodog.rotation(deflib.RotateDirection.Clockwise, 90, 50) 각도 0~360, 빠르기 10~100. Clockwise = 오른쪽(시계 방향) ○ makecode/21_remote-dog.ts
왼쪽으로 돌기 (로보독) 회전 robodog.rotation(deflib.RotateDirection.Counterclockwise, 30, 80) Counterclockwise = 왼쪽 ○ makecode/12_button-explore.ts
앉기·인사·서기 등 자세 (로보독) 자세 robodog.gesture(deflib.Posture.SitDown) Ready(서기) · SitDown(앉기) · Handstand(물구나무) · Stretch(기지개) · SayHello(인사) △ 근사 자세 makecode/01_hello-robodog.ts, makecode/05_motion-tour.ts
몸을 낮게·높게 (로보독) 다리 높이 robodog.legBend(deflib.LegGroup.AllLegs, 70) 높이 0~100. 다리 묶음: AllLegs FrontLegs BackLegs LeftLegs RightLegs ○ makecode/05_motion-tour.ts
다리 하나씩 움직이기 (로보독) 다리 robodog.leg(deflib.LegSelection.RightFront, 100, 80) 높이 0~100, 앞뒤 -100~100 ○ makecode/05_motion-tour.ts
관절 각도로 움직이기 (로보독) 모터 robodog.motor(…) 각도는 -90~90으로 잘려요 ○ makecode/05_motion-tour.ts
  • 걷기 모드와 다리 모드는 섞이지 않아요. 앉기·다리 블록을 쓰다가 걷기 블록을 쓰면 이동·회전 값이 처음으로 돌아가요. 걷기 전에 robodog.gesture(deflib.Posture.Ready)로 서게 하면 안전해요.
  • robodog.rotation은 "돌아라"라고 시켜 두고 바로 다음 줄로 넘어가요. 다 돌 때까지 기다리려면 basic.pause를 같이 써요 (90도, 빠르기 60이면 약 1.3초).

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
눈 표정 바꾸기 (로보독) 눈 표정 robodog.headLedExp(deflib.LedExpression.SparklingEyes) 14가지: SparklingEyes(초롱초롱) ILoveYou EyesClosed(눈 감기) Thanks ThankYou Sparrow RollingEyes(좌우 굴리기) SharpEyes(찢눈) BlinkingSharpEyes Insect Blink(깜박) SnakeEyes Pinwheel BigEyes(왕눈이) △ 모양은 근사 makecode/10_button-bark.ts

눈 끄기 (로보독) 눈 지우기 robodog.headLedClear() ○ makecode/04_ai-team-template.ts
몸통 불빛 색 (로보독) 몸통 LED robodog.bodyLed(255, 0, 0) 빨강·초록·파랑 각각 0~255. (255,0,0) 빨강, (0,255,0) 초록, (0,0,255) 파랑, (0,0,0) 끄기 ○ makecode/02_distance-rule.ts
소리 내기 (로보독) 효과음 robodog.soundPlay(deflib.SoundEffect.Bark, deflib.SoundVolume.Medium) 소리: Bark(멍멍) Growl Angry Whine HeavyBreath Hello Wait MoveAside Start Laser MotorRotation DingDing AlienSignal Motion Collision 와 음계 Do Re Mi Fa Sol La Si SharpDo. 크기: Quiet(1) Medium(2) Loud(3) △ 비슷한 신호음 + 말풍선 (소리는 기본 꺼짐) makecode/10_button-bark.ts
마이크로비트 화면에 숫자·글자·그림 기본 → 숫자 보이기 / 문자열 보이기 / 아이콘 보이기 basic.showNumber(3) · basic.showString("HI") · basic.showIcon(IconNames.Heart) 5×5 불빛 화면. 한 글자는 잠깐 보이고, 긴 글은 흘러가요 ○ makecode/02_distance-rule.ts
  • 로보독 마이크로비트에서는 '음악' 블록을 쓰지 마세요. 로봇과 통신하는 핀과 겹칠 수 있어요. 소리는 위의 효과음 블록을 써요. (시뮬레이터도 경고를 띄워요.)
  • 등에 꽂은 마이크로비트의 5×5 화면은 잘 안 보일 수 있어요. 눈 표정이나 몸통 불빛으로도 알려 주세요.

3. 센서로 알기

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
앞의 물건까지 거리 알기 (거리센서 = 빛으로 거리를 재는 눈) (로보독) 거리 let 거리 = robodog.getTof() 시뮬레이터: 머리 앞에서 물건까지 cm, 아무것도 없으면 255. 실물은 단위를 아직 확인하지 못했어요. 실물에서 0은 "값을 못 읽었다"는 뜻으로 쓰고 있어요 ○ makecode/02_distance-rule.ts
로보독 방향 알기 (로보독) 방향 robodog.getRotation() 시뮬레이터는 -180~180으로 줘요 ○ (예제 없음)
몸이 기울었는지 알기 (로보독) 기울기 robodog.getTilt(deflib.TiltAxis.LeftRight) LeftRight / ForwardBackward. 시뮬레이터는 늘 0 (평평) △ (예제 없음)
배터리 (로보독) 배터리 robodog.getBattery() 시뮬레이터에서는 패널의 막대 값 △ (예제 없음)
빛·온도·소리 크기 입력 → 빛 세기 등 input.lightLevel() 시뮬레이터는 고정값(빛 128, 온도 22) ✕ (예제 없음)

거리센서 쓸 때 꼭 지켜요

  • getTof()가 0이면 값이 없는 것이니 "가깝다"로 읽지 말고 거리 > 0 && 거리 < 20처럼 0을 빼요. (makecode/02_distance-rule.ts도 0이면 안전하게 멈춰요.)
  • 거리센서는 앞만 봐요. 뒤로 걸을 때나 책상 끝(낭떠러지)은 알지 못해요.
  • "가깝다"의 기준(예: 20)은 모둠이 직접 손을 대 보고 정해요.

4. 본체 버튼

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
로보독 본체 버튼 눌렸는지 알기 (로보독) 버튼 let 지금버튼 = robodog.getButton() 누르는 순간 잠깐 true(참), 아니면 false ○ [본체 버튼 누르기] makecode/10_button-bark.ts
"한 번 눌렀을 때" 한 번만 하기 만약 … 이고 … 아니라면 if (지금버튼 && !(이전버튼)) { … } + 맨 끝에 이전버튼 = 지금버튼 지금은 눌렸고, 조금 전엔 안 눌렸으면 = 방금 누른 순간 ○ 본체 버튼 예제 모두
(참고) 마이크로비트 A·B 버튼 입력 → 버튼 A 눌렀을 때 input.onButtonPressed(Button.A, function () { … }) A, B, A+B(Button.AB) ○ 단, 실물 로보독에서는 A·B가 가려져 눌 수 없어요 makecode/20_remote-sender.ts (리모컨용)

5. 라디오 (숫자 주고받기)

라디오는 마이크로비트끼리 전파로 숫자를 주고받는 기능이에요. 같은 모둠 번호(라디오 그룹)끼리만 들려요.

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
모둠 번호 정하기 무선 통신 → 무선 그룹 설정 radio.setGroup(1) 리모컨과 로보독이 같은 번호여야 해요. 모둠마다 다르게 ○ makecode/20_remote-sender.ts, makecode/21_remote-dog.ts
숫자 보내기 (리모컨 쪽) 무선 통신 → 숫자 보내기 radio.sendNumber(1) 약속: A=1, B=2, A+B=3 △ 실행 기록에 "라디오 보냄"만 남겨요 makecode/20_remote-sender.ts
숫자 받으면 움직이기 (로보독 쪽) 무선 통신 → 받은 숫자 radio.onReceivedNumber(function (receivedNumber) { … }) receivedNumber가 받은 숫자 ○ 로보독 화면 위 [📡 리모컨] 줄의 숫자 버튼 makecode/21_remote-dog.ts, makecode/22_remote-tricks.ts
글자·이름과 값 주고받기 무선 통신 → 글자/값 보내기·받기 radio.sendString("go") · radio.sendValue("속도", 25) △ 보내기는 기록만, 받기는 시뮬레이터에서 시험할 수 없어요 (예제 없음)
  • 시뮬레이터의 숫자 버튼은 한 번 누르면 한 번만 보내요. 2초 동안 신호가 없으면 멈추는 코드(makecode/03_ai-traffic-dog.ts)는 [📡 리모컨] 줄의 [계속 보내기]를 켜세요.
  • 시뮬레이터에는 리모컨이 따로 없으니 리모컨 코드(makecode/20_remote-sender.ts)를 돌릴 필요는 없어요. 로보독 코드만 돌리고 숫자 버튼을 눌러요.

6. 기다리기 · 반복 · 조건 · 변수

변수는 숫자를 담아 두는 이름표 상자예요. 예: let 가까움 = 20이라고 하면 "가까움"이라는 상자에 20이 들어 있어요.

하고 싶은 일 블록에 보이는 말 글자 코드 예 숫자 뜻·범위 시뮬레이터 예제 파일
잠깐 기다리기 기본 → 일시 중지 (ms) basic.pause(1000) 1000 = 1초. 걷다가 멈추기 전에 시간을 줄 때 써요 ○ makecode/12_button-explore.ts
계속 반복하기 기본 → 무한 반복 basic.forever(function () { … }) 안에서는 마지막에 basic.pause(50)처럼 조금 쉬어요 ○ 모든 본체 버튼 예제
만약 ~라면 / 아니면 만약 … 아니면 if (거리 < 20) { … } else { … } 비교: < > ==(같다) !=(다르다), 그리고 &&, 또는 || ○ makecode/02_distance-rule.ts
숫자를 담아 두기 변수 let 걷는중 = false · 걷는중 = !(걷는중) true/false로 켜짐·꺼짐을 기억해요. !은 반대로 바꾸기 ○ makecode/02_distance-rule.ts
아무 숫자 고르기 계산 → 무작위 randint(30, 180) 30~180 중 아무 숫자 ○ makecode/12_button-explore.ts
시작한 뒤 흐른 시간 입력 → 실행 시간 (ms) input.runningTime() 1000 = 1초 ○ makecode/12_button-explore.ts
나만의 블록(함수) 만들기 함수 function 두리번 () { … } 자주 쓰는 동작 묶음에 이름 붙이기 ○ makecode/12_button-explore.ts

7. AI 카메라 값 (무선 확장 kocoafab/robodog-radio)

로보독 눈 사이의 카메라가 얼굴·색·QR 카드를 알아봐요. 시뮬레이터에는 카메라가 없어서 값이 늘 "인식 없음"(숫자는 0, QR은 "none")이에요. 코드가 실행은 되지만 카메라 값에 따라 움직이는 모습은 볼 수 없어요. 실물에서 확인하세요.

하고 싶은 일 글자 코드 예 숫자 뜻 시뮬레이터 예제 파일
카메라 모드 고르기 robodog.aiDetection(deflib.AiMode.QrCode) Camera FaceDetect FaceTracking ColorDetect QrCode △ 안내만 makecode/06_radio-ai-qr.ts, makecode/07_radio-ai-color.ts
얼굴 따라가기 모드 robodog.faceTracking(deflib.AiClass.Class1) 학습한 종류 Class1~Class5 △ 안내만 makecode/08_radio-ai-face.ts
QR 카드 글자 읽기 let 값 = robodog.getQrCode() 글자(예 "GO"). 없으면 "none" ✕ 늘 "none" makecode/06_radio-ai-qr.ts
색 알아보기 let 색 = robodog.getColorDetect() 0 = 못 알아봄, 1 이상 = 색 번호 ✕ 늘 0 makecode/07_radio-ai-color.ts

얼굴의 가로 위치 robodog.getAiPosition(deflib.AiPositionAxis.X) X(가로) Y(세로) ✕ 늘 0 makecode/08_radio-ai-face.ts

8. 아이디어 → 블록 조합 예

조합 ① 벽에 가까워지면 짖고, 뒤로 물러났다가 돌기

필요한 블록: 걷기, 거리센서, 효과음, 뒤로 걷기, 회전, 기다리기.

let 가까움 = 20
robodog.gesture(deflib.Posture.Ready)
robodog.move(deflib.MoveDirection.Forward, 25)
basic.forever(function () {
    let 거리 = robodog.getTof()
    if (거리 > 0 && 거리 < 가까움) {
        robodog.stop()
        robodog.soundPlay(deflib.SoundEffect.Bark, deflib.SoundVolume.Medium)
        robodog.move(deflib.MoveDirection.Backward, 20)
        basic.pause(1000)
        robodog.stop()
        robodog.rotation(deflib.RotateDirection.Clockwise, 90, 60)
        basic.pause(1500)
        robodog.move(deflib.MoveDirection.Forward, 25)
    }
    basic.pause(50)
})

팁: 앞뒤로 떠는 현상. 뒤로 조금 물러난 뒤 바로 다시 앞으로 걸으면, 아직 벽이 "가까움" 기준 안에 있어서 다시 짖고 다시 물러나요. 로보독이 앞뒤로 떨게 돼요. 돌기를 사이에 넣으면 벽을 보지 않는 쪽으로 가니까 해결돼요. 돌기를 시킨 뒤 basic.pause(1500)으로 다 돌 때까지 기다리는 것도 잊지 마세요.

조합 ② 리모컨으로 조종하다가 장애물 앞에서 자동 정지

로보독에 꽂는 마이크로비트용이에요. 리모컨은 makecode/20_remote-sender.ts(A=1 걷기, B=2 멈춤)를 그대로 써요.

let 걷는중 = false
radio.setGroup(1)
robodog.gesture(deflib.Posture.Ready)
radio.onReceivedNumber(function (receivedNumber) {
    if (receivedNumber == 1) {
        걷는중 = true
        robodog.bodyLed(0, 255, 0)
        robodog.move(deflib.MoveDirection.Forward, 25)
    } else if (receivedNumber == 2) {
        걷는중 = false
        robodog.stop()
        robodog.bodyLed(255, 0, 0)
    }
})
basic.forever(function () {
    if (걷는중) {
        let 거리 = robodog.getTof()
        if (거리 > 0 && 거리 < 20) {
            걷는중 = false
            robodog.stop()
            robodog.bodyLed(255, 160, 0)
            robodog.soundPlay(deflib.SoundEffect.Wait, deflib.SoundVolume.Medium)
        }
    }
    basic.pause(50)
})

시뮬레이터에서는 장애물을 앞에 놓고 로보독 화면 위 [📡 리모컨] 줄의 1을 눌러요. 걷다가 주황 불과 함께 멈추면 성공이에요. 멈춘 뒤 1을 또 누르면 다시 걷기 시작하니, 장애물 앞에서는 다른 쪽으로 돌려 주는 블록을 더 넣어 보세요. 이 생각을 완성한 예제가 makecode/23_remote-safe-dog.ts(리모컨 ⑥)예요.

조합 ③ 본체 버튼으로 켜고 끄기

let 켜짐 = false
let 이전버튼 = false
robodog.gesture(deflib.Posture.Ready)
basic.forever(function () {
    let 지금버튼 = robodog.getButton()
    if (지금버튼 && !(이전버튼)) {
        켜짐 = !(켜짐)
        if (켜짐) {
            robodog.bodyLed(0, 255, 0)
            robodog.headLedExp(deflib.LedExpression.SparklingEyes)
            robodog.move(deflib.MoveDirection.Forward, 25)
        } else {
            robodog.stop()
            robodog.bodyLed(255, 0, 0)
            robodog.headLedExp(deflib.LedExpression.EyesClosed)
        }
    }
    이전버튼 = 지금버튼
    basic.pause(50)
})

[▶ 실행]만 누르면 가만히 있는 게 정상이에요. [본체 버튼 누르기]를 누르면 걷고, 한 번 더 누르면 멈춰요.

9. 시뮬레이터와 실물이 다를 수 있는 것

(자세한 표: 시뮬레이터 안내)

  • 걷는 속도·돌기 빠르기: 속도 100 ≈ 15cm/초, 빠르기 100 ≈ 120도/초는 추정치예요. basic.pause 시간은 실물에서 다시 맞춰요.
  • 거리센서: 단위(cm로 가정)를 실물에서 확인하지 못했어요. 시뮬레이터는 없을 때 255를 주지만 코드는 "0 = 값 없음"도 처리하도록 짜요.
  • 눈 표정 모양, 자세(앉기·물구나무·기지개·인사): 근사 그림이에요. 실제 모양과 각도는 달라요.
  • 효과음: 실제 소리가 아니라 비슷한 신호음과 말풍선이에요.
  • 걷는 다리 모양: 대각선 두 다리씩 걷는 근사예요. 미끄러짐·넘어짐은 없어요. 배터리는 막대 값이에요.
  • 눈에 글자: 시뮬레이터는 영문·숫자 한 글자만 표시해요.
  • 라디오: 보내기는 기록만 남고, 받기는 패널 숫자 버튼(또는 AI 브리지)으로만 시험해요. 신호가 끊기는 상황은 직접 만들어야 해요.
  • 마이크로비트 A·B 버튼: 시뮬레이터에서는 눌리지만 실물 로보독에서는 가려져요.
  • 방향·기울기: 방향 값은 -180~180으로 정리해서 줘요(실물은 범위가 다를 수 있음). 기울기는 늘 0이에요.
  • 빛·온도·소리 크기: 고정값이에요.
  • AI 카메라: 늘 "인식 없음"이에요.
  • 지원하지 않는 블록: 음악, 게임, 핀, 가속도(흔들기) 등은 실행은 되지만 기록에 "지원하지 않는 블록"으로 떠요.
  • 책상 가장자리: 거리센서는 책상 끝을 못 봐요. 시뮬레이터는 "떨어졌어요" 경고를 보여 주지만 실물은 정말 떨어져요. 걷는 코드는 바닥이나 울타리 안에서 시험하세요.

시뮬레이터에서 잘 되는 코드도 실물에서는 속도·거리 값이 달라질 수 있어요. 수업 전에 실물로 한 번 확인하세요.
