진짜 MakeCode 편집기예요(makecode.microbit.org). 로보독 확장이 미리 들어 있어요. 블록을 고치면 오른쪽 로보독이 그대로 움직여요. 마이크로비트에 내려받기는 편집기 아래 [다운로드]를 쓰세요. 프로젝트는 이 화면의 코드 칸에 저장돼요.

블록 그림은 MakeCode(makecode.microbit.org) 공식 렌더링 서비스로 만들어요(코드가 그쪽으로 전달되며 인터넷이 필요해요). 보기 전용이에요. 고치려면 JavaScript 탭에서 고치거나, [코드 복사] → MakeCode의 JavaScript 탭에 붙여넣고 블록 탭으로 바꾸세요.

⚠ 시뮬레이터는 미리 보기입니다. 걷는 속도(속도 100 ≈ 15cm/초)·회전 빠르기·크기·거리센서 단위(cm로 가정)·눈 표정 모양은 실물과 다를 수 있는 추정치예요. 실제 로보독에서 꼭 다시 확인하세요.
