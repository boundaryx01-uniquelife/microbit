- 비트런(다른 로봇) 활동 2종(squat, rescue)의 그림은 넣지 않았다. `activities.json`에는 원본 그대로 8종이 있고 `robot` 값(`pony`/`bitrun`)으로 구분한다.
- ai-playground 저장소에는 그림 라이선스 파일이 없다 → 제조사 허락 범위 안에서만 쓰고, 다른 곳에 재배포하기 전에 다시 확인한다.
- 바운더리엑스 홈페이지(boundaryx.io)는 작업 환경에서 '접근 제한'(403)으로 열리지 않았다. 홈페이지의 슬라이드·제품 사진은 받지 못했다(필요하면 파일로 받아 추가).
- README 속 제품 사진(github user-attachments)은 로그인이 필요해 받지 못했다.
