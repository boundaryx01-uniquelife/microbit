AI 웹앱 — 블루투스로 포니봇 움직이기

바운더리엑스가 만든 공식 웹앱이에요(새 탭에서 열려요). 웹앱 안의 사용 가이드 → 마이크로비트 예제 코드 링크를 눌러 MakeCode에서 연 뒤 포니봇의 마이크로비트에 내려받고, 웹앱에서 블루투스로 연결하면 됩니다.

✋ KNN 핸드포즈 분류 ↗손 모양(주먹·보·브이·가리키기)을 ID1~ID5로 가르치고, 알아본 ID를 블루투스로 보내요(손이 사라지면 stop) — 3교시 🎤 AI 음성 인식 ↗말을 글자로 바꿔 블루투스로 보내요. 명령어에 ID1~ID5를 등록하면 3교시 코드 그대로 움직여요 — 4교시
  1. 웹앱의 블루투스 이름 확인 코드를 먼저 마이크로비트에 내려받아 LED에 나오는 이름(소문자 5자리)을 확인해요.
  2. 포니봇 블루투스 예제 코드를 시뮬레이터에서 열고(🔵 블루투스 줄로 먼저 시험), 블록 편집기 아래 [다운로드]로 포니봇의 마이크로비트에 내려받아요. 블루투스 코드는 라디오와 함께 쓸 수 없어요. 웹앱 연결 목록에서 내 포니봇 이름(다섯 글자)이 헷갈리면 이름 확인 예제(6번)를 먼저 넣어 보세요. MakeCode에서 직접 만들 때는 톱니바퀴 → 프로젝트 설정 → 페어링이 필요하지 않습니다를 켜야 연결돼요(시뮬레이터 [다운로드]는 자동).
  3. 웹앱에서 [연결]을 눌러 그 이름의 마이크로비트를 고르고, 인식을 시작해요.

⚠ 블루투스 연결(Web Bluetooth)은 크롬·엣지(PC·안드로이드)에서 돼요. 아이폰·아이패드의 사파리는 지원하지 않아요. 웹앱은 카메라·마이크 권한이 필요하고 인터넷에 연결돼 있어야 해요. 연결이 끊겨도 포니봇이 멈추도록 마이크로비트 쪽 코드에 멈춤 처리를 넣으세요.

4차시 수업 슬라이드의 3·4교시가 이 웹앱 실습(핸드포즈 → 음성 → 로봇 리믹스 카드 뽑기 ↗)이에요. 시뮬레이터는 블루투스 받기를 흉내 내지 않아요(라디오 숫자 칸은 예전 방식).

말로 코드 만들기 — 포니봇다운 예시 2가지

시뮬레이터의 말로 만들기 칸에 아래 문장을 그대로 넣으면 블록 코드가 만들어져요. 기본은 인터넷이 없어도 되는 규칙 도우미가 만들고, 이때 글은 컴퓨터 밖으로 나가지 않아요. 선생님께 받은 수업 코드를 넣으면 AI 도우미(Claude)가 더 자유로운 문장도 만들어요(이때는 글이 AI 서버로 보내져요). [시뮬레이터에서 해 보기]를 누르면 문장이 들어간 채로 열려요 → ▶ 시뮬레이터에서 실행 → 오른쪽 A 버튼.

① 옆으로 주차하고, 대각선으로 나오기 메카넘 바퀴

A 버튼을 누르면 OLED에 "PARK" 라고 쓰고 앞으로 1초 가고 오른쪽 옆으로 2초 가고 멈춰. B 버튼을 누르면 OLED에 "OUT" 라고 쓰고 왼쪽 앞 대각선으로 2초 가고 멈춰
  • A 버튼: 화면에 PARK → 앞으로 → 몸은 앞을 본 채 오른쪽 옆으로 들어가 멈춤
  • B 버튼: 화면에 OUT → 왼쪽 앞 대각선(↖)으로 빠져나와 멈춤
  • 확인할 것: 2D 화면의 파란 선(지나간 자리)이 ㄱ자와 대각선으로 그려지고, 포니봇 몸 방향은 바뀌지 않아요
시뮬레이터에서 해 보기 →

② 선을 따라가다 색을 보고 판단하기 라인 센서 + 컬러 센서 + 거리센서

A 버튼을 누르면 검은 선을 따라가다가 초록색이 보이면 2초 쉬었다가 다시 가고, 빨간색이 보이면 멈추고 OLED에 "RED" 라고 써. 앞이 15cm보다 가까우면 기다려, 직진 속도는 35, 회전 속도는 75로 설정해줘
  • 실행하면 시뮬레이터가 검은 선과 초록·빨강 칩을 자동으로 놓아 줘요
  • A 버튼: 선을 따라 출발 → 초록 칩에서 2초 쉬었다가 다시 출발 → 빨강 칩에서 멈추고 화면에 RED
  • 확인할 것: 선 앞에 상자를 놓으면(✏ 물체 놓기) 15cm 앞에서 기다렸다가, 치우면 다시 가요. B 버튼 = 멈춤
시뮬레이터에서 해 보기 →

시뮬레이터는 추정 모델이에요. 실물에서 라인·컬러 센서가 같은 값을 읽는지, 속도 100에서 선을 놓치지 않는지는 확인이 필요해요(속도는 문장에 "속도 70으로"처럼 넣어 바꿀 수 있어요).

수업 전 꼭 확인할 것 (실물 미검증)

아래는 확장 코드로만 확인했고 실물로는 아직 확인하지 않았습니다. 수업 전에 선생님이 직접 확인해 주세요.

  • 메카넘 9방향·제자리 회전(↶/↷)이 화면 글자대로 움직이는지 (0번 점검 예제로 확인)
  • 예제 속도에서 바퀴가 확실히 도는지, 1초에 얼마나 가는지
  • 포니봇에 꽂은 마이크로비트의 A·B 버튼을 누를 수 있는지
  • 초음파 거리센서: 손을 대면 숫자가 줄어드는지, 반사가 없을 때 500이 나오는지
  • 라디오 수신: USB 마이크로비트와 같은 모둠번호에서 2초 안에 신호가 오는지

속도·가까움 기준 같은 값은 예시입니다(예제 기본 속도 200, 범위 0~255). 교실 환경에 맞게 선생님이 정해 주세요.
