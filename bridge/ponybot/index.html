카드를 웹캠으로 AI에게 가르치고 → 인식한 번호를 USB 마이크로비트가 라디오로 보내고 → AI 포니봇에 꽂은 마이크로비트가 받아 움직입니다.

MakeCode 예제 내려받기

makecode.microbit.org → 새 프로젝트 → 확장에 https://github.com/boundary-x/ai_ponybot_basic 입력해 추가 → 내려받은 파일을 가져오기(또는 JavaScript 탭에 붙여넣기). 00_bridge-receiver는 컴퓨터에 꽂는 마이크로비트용이라 확장이 필요 없습니다.

  • 00_bridge-receiver.ts USB 마이크로비트(컴퓨터에 꽂는 것) — 확장 없이
  • 00_check-ponybot.ts 0. 연결·센서 점검 (수업 전 1분)
  • 01_hello-ponybot.ts 1. 안녕, 포니봇! (순차 구조)
  • 02_distance-rule.ts 2. 규칙으로 반응하기 (센서 + 조건문)
  • 03_ai-traffic-ponybot.ts 3. AI 신호등 포니봇
  • 04_ai-team-template.ts 4. 우리 모둠 AI 포니봇 (프로젝트 틀)

수업 전 꼭 확인할 것 (실물 미검증)

아래는 확장 코드로만 확인했고 실물로는 아직 확인하지 않았습니다. 수업 전에 선생님이 직접 확인해 주세요.

  • 메카넘 9방향·제자리 회전(↶/↷)이 화면 글자대로 움직이는지 (0번 점검 예제로 확인)
  • 예제 속도에서 바퀴가 확실히 도는지, 1초에 얼마나 가는지
  • 포니봇에 꽂은 마이크로비트의 A·B 버튼을 누를 수 있는지
  • 초음파 거리센서: 손을 대면 숫자가 줄어드는지, 반사가 없을 때 500이 나오는지
  • 라디오 수신: USB 마이크로비트와 같은 모둠번호에서 2초 안에 신호가 오는지

속도·가까움 기준 같은 값은 예시입니다(예제 기본 속도 80, 범위 0~255). 교실 환경에 맞게 선생님이 정해 주세요.
